# 00-13 AI测试系统 - 报告中心 PRD

## 1. 这份文档解决什么问题

报告中心用于统一查看 UI 自动化执行结果、Allure 报告索引、失败诊断结果和质量摘要。Allure 负责测试执行细节，系统报告中心负责业务聚合、来源追踪、跳转和诊断入口。

核心规则：

- 第一期自动化报告以 UI 自动化为主。
- Allure 报告是执行详情标准产物，不重复自研完整测试报告引擎。
- 系统报告中心提供摘要、筛选、跳转、趋势和失败诊断入口。
- 接口自动化报告第一期不生成，只保留 Soon 说明。

---

## 2. 业务边界

### 2.1 本模块负责

- 展示自动化运行记录。
- 展示执行摘要、通过率、失败用例、耗时。
- 关联 Allure 报告目录和入口。
- 展示失败诊断结论。
- 支持按项目、套件、时间、状态筛选。
- 支持从报告跳转到测试用例、自动化代码、失败诊断。

### 2.2 本模块不负责

- 不执行测试。
- 不生成 pytest 代码。
- 不替代 Allure 步骤详情、截图、trace、附件展示。
- 不对接外部缺陷系统，第一版只保留内部 Bug 记录。

---

## 3. 页面结构

### 3.1 报告中心首页

核心区域：

- 执行概览卡片：总运行次数、通过率、失败数、产品 Bug 数、代码问题数、平均耗时。
- 最近运行记录。
- 失败趋势。
- 高风险项目。
- 待诊断失败。

### 3.2 运行记录

字段：

- 运行编号
- 项目
- 自动化类型：UI
- 套件名称
- 触发方式：手动、本地任务、自愈验证
- 执行状态
- 用例总数
- 通过数
- 失败数
- 跳过数
- 开始时间
- 耗时
- Allure 报告入口
- 失败诊断入口

### 3.3 运行详情

必须展示：

- 执行摘要
- 用例结果列表
- 失败用例列表
- 关联测试用例
- 关联自动化代码路径
- Allure 报告链接
- 截图、trace、video 附件索引
- 失败诊断状态和结论

### 3.4 Allure 报告入口

系统只保存 Allure 报告索引：

- Allure results 路径
- Allure report 路径
- 报告生成时间
- 报告访问 URL 或本地路径
- 关联运行编号

点击 Allure 报告时：

- 如果报告已生成，打开报告。
- 如果报告不存在，提示重新生成。
- 如果本地路径不可访问，提示检查本地 Runner 配置。

## 4. 失败分类展示

| 分类 | 说明 | 后续动作 |
| --- | --- | --- |
| 产品 Bug | 页面行为与需求、知识库或断言不一致 | 记录内部 Bug，禁止自愈通过 |
| 自动化代码问题 | locator、等待、断言或代码结构问题 | 可人工启用自愈 |
| 测试数据问题 | 前置数据缺失或状态不满足 | 补充数据或调整用例 |
| 环境问题 | 服务不可用、网络异常、依赖异常 | 重新执行或标记环境问题 |
| 需求不清楚 | 无法判断预期 | 生成澄清问题 |
| 未诊断 | 尚未执行诊断 | 可发起诊断 |

---

## 5. 数据对象

### 5.1 AutomationRunReport

| 字段 | 说明 |
| --- | --- |
| 报告 ID | 系统唯一 |
| 项目 ID | 所属项目 |
| 运行 ID | UI 自动化运行记录 |
| 自动化类型 | UI，接口自动化预留 |
| 总数 | 用例总数 |
| 通过数 | 通过用例数 |
| 失败数 | 失败用例数 |
| 跳过数 | 跳过用例数 |
| Allure results 路径 | 本地路径 |
| Allure report 路径 | 本地路径 |
| 报告状态 | 生成中、可查看、生成失败、已过期 |
| 创建时间 | 系统生成 |

### 5.2 InternalBugRecord

| 字段 | 说明 |
| --- | --- |
| Bug ID | 系统唯一 |
| 项目 ID | 所属项目 |
| 来源运行 | 自动化运行 |
| 来源用例 | 测试用例 |
| 标题 | 缺陷标题 |
| 分类 | 产品 Bug |
| 严重程度 | 高、中、低 |
| 复现步骤 | 从测试步骤和执行日志生成 |
| 期望结果 | 来源于用例或知识库 |
| 实际结果 | 来源于执行结果 |
| 状态 | 新建、已确认、已关闭、已废弃 |

## 6. 权限规则

| 操作 | 管理员 | 测试工程师 | 访客 |
| --- | --- | --- | --- |
| 查看报告 | 是 | 分配项目 | 是 |
| 查看 Allure | 是 | 分配项目 | 是 |
| 发起失败诊断 | 是 | 分配项目 | 否 |
| 记录内部 Bug | 是 | 分配项目 | 否 |
| 修改 Bug 状态 | 是 | 分配项目 | 否 |

---

## 7. 验收标准

- UI 自动化执行完成后能在报告中心看到运行记录。
- 每次运行能跳转到 Allure 报告。
- 失败用例能跳转到失败诊断。
- 诊断为产品 Bug 的失败能生成内部 Bug 记录。
- 报告中心不统计接口自动化结果。
- 访客可以查看报告但不能发起诊断或修改 Bug。
