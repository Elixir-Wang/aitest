# 00-14 AI测试系统 - 用户配置 PRD

## 1. 这份文档解决什么问题

用户配置用于管理个人账号信息、密码、安全设置和工作偏好。第一版不开放用户自行注册，账号由管理员创建。

核心规则：

- 用户不能自助注册。
- 管理员创建账号并分配角色。
- 用户可以维护个人信息和偏好，但不能自行提升权限。
- 访客只读，不允许修改系统数据。

---

## 2. 业务边界

### 2.1 本模块负责

- 查看个人信息。
- 修改昵称、头像、联系方式。
- 修改密码。
- 设置默认项目。
- 设置默认进入页面。
- 设置通知偏好。

### 2.2 本模块不负责

- 不负责创建账号，账号创建属于用户与权限。
- 不负责项目分配，项目分配属于权限管理。
- 不负责模型配置。
- 不负责系统级安全策略。

---

## 3. 用户个人信息

| 字段 | 说明 | 是否可编辑 |
| --- | --- | --- |
| 用户名 | 登录账号 | 否 |
| 昵称 | 页面展示名 | 是 |
| 邮箱 | 联系方式 | 是 |
| 手机号 | 联系方式 | 是 |
| 头像 | 可选头像 | 是 |
| 角色 | 管理员、测试工程师、访客 | 否 |
| 状态 | 启用、禁用 | 否 |
| 最近登录时间 | 系统记录 | 否 |

---

## 4. 个人偏好

| 偏好 | 说明 |
| --- | --- |
| 默认项目 | 登录后默认选择的项目 |
| 默认首页 | 控制台、任务中心、项目列表 |
| 表格分页大小 | 10、20、50、100 |
| 任务提醒范围 | 待澄清、待评审、失败诊断、自愈确认 |
| 报告打开方式 | 系统详情优先或 Allure 优先 |

---

## 5. 密码修改

规则：

- 用户可修改自己的密码。
- 修改密码必须输入旧密码。
- 新密码必须符合系统密码策略。
- 修改成功后可选择是否退出其他会话，第一版可只保留当前会话。
- 管理员重置密码属于权限管理，不属于个人配置。

---

## 6. 页面设计

### 6.1 个人资料

功能：

- 查看账号基本信息。
- 修改昵称、邮箱、手机号、头像。
- 查看角色和账号状态。

### 6.2 安全设置

功能：

- 修改密码。
- 查看最近登录时间。
- 后续预留 MFA、登录设备管理。

### 6.3 工作偏好

功能：

- 设置默认项目。
- 设置默认首页。
- 设置任务提醒范围。
- 设置报告打开偏好。

---

## 7. 权限规则

| 操作 | 管理员 | 测试工程师 | 访客 |
| --- | --- | --- | --- |
| 查看自己资料 | 是 | 是 | 是 |
| 修改自己资料 | 是 | 是 | 是 |
| 修改自己密码 | 是 | 是 | 是 |
| 修改自己角色 | 否 | 否 | 否 |
| 修改项目分配 | 否 | 否 | 否 |

---

## 8. 验收标准

- 用户能查看个人资料。
- 用户能修改昵称、邮箱、手机号等个人信息。
- 用户能修改自己的密码。
- 用户不能修改自己的角色和项目权限。
- 默认项目和默认首页设置能影响下次进入系统后的默认视图。
