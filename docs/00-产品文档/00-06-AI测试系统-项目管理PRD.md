# 00-06 AI测试系统 - 项目管理 PRD

## 1. 这份文档解决什么问题

本文只细化项目管理。项目是 AI 测试系统第一业务边界，需求文档、站点探索、知识库、测试用例、UI 自动化代码、执行记录和报告都必须归属于项目；接口自动化第一期只预留入口，不产生项目资产。

权限管理见：

- `00-02-AI测试系统-权限管理PRD.md`

控制台见：

- `00-07-AI测试系统-控制台PRD.md`

---

## 2. 项目边界

### 2.1 项目负责隔离

- 源文档
- 需求分析
- 澄清问题
- 站点探索
- 知识库
- 测试用例
- UI 自动化测试代码
- 执行记录
- Allure 报告索引
- 失败诊断和自愈记录

### 2.2 项目不负责

- 不负责系统级模型 Provider 配置
- 不负责全局用户管理
- 不负责跨项目共享知识库，第一版不做

---

## 3. 项目字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 项目名称 | 是 | 页面展示名称 |
| 项目编码 | 是 | 项目内唯一编码，用于目录和任务归属 |
| 项目描述 | 否 | 测试项目背景，在项目列表中展示为描述列 |
| 默认站点地址 | 否 | 后续站点探索默认地址 |
| 默认环境 | 否 | 本地、测试、预发、生产等文本值 |
| 负责人 | 否 | 管理员或测试工程师 |
| 创建时间 | 是 | 系统生成 |
| 更新时间 | 是 | 系统生成 |
| 归档时间 | 否 | 为空表示正常项目，有值表示已归档 |

第一版不设计复杂“项目状态”，避免用户需要维护一个难以定义的状态字段。项目只保留生命周期控制：正常、已归档。正常项目不展示状态标签；已归档项目在项目名称旁展示“已归档”标签，并禁止新建任务。

---

## 4. 项目动作

| 动作 | 管理员 | 测试工程师 | 访客 |
| --- | --- | --- | --- |
| 创建项目 | 可执行 | 不可执行 | 不可执行 |
| 编辑项目 | 可执行 | 不可执行 | 不可执行 |
| 分配测试工程师 | 可执行 | 不可执行 | 不可执行 |
| 查看项目 | 可查看全部 | 仅分配项目 | 可查看全部 |
| 归档项目 | 可执行 | 不可执行 | 不可执行 |
| 恢复项目 | 可执行 | 不可执行 | 不可执行 |

第一版不做物理删除，避免误删测试资产。

---

## 5. 项目列表

项目列表不是项目健康看板，只负责让用户快速找到项目、理解项目资产规模并进入项目详情。复杂信息不堆在列表列中，统一放到“查看”后的项目概览页。

### 5.1 列表字段

- 项目名称
- 描述
- 测试工程师数量
- 需求文档数量
- 知识库版本
- 测试用例数量
- UI 自动化用例数量
- 最近更新时间
- 操作

列表字段说明：

| 字段 | 展示规则 |
| --- | --- |
| 项目名称 | 主标题；如果项目已归档，在名称旁展示“已归档”标签 |
| 描述 | 展示项目描述，超长省略，悬停或详情中查看完整内容 |
| 测试工程师数量 | 当前分配到项目的测试工程师数量 |
| 需求文档数量 | 项目下上传或生成的需求文档数量 |
| 知识库版本 | 当前正式知识库最新版本号；没有知识库时展示“未生成” |
| 测试用例数量 | 项目下测试用例总数 |
| UI 自动化用例数量 | 已生成 UI 自动化代码且可执行的用例数量 |
| 最近更新时间 | 项目自身或项目资产最近更新时间 |
| 操作 | 查看、编辑 |

不建议展示的信息：

| 信息 | 不放在列表的原因 | 展示位置 |
| --- | --- | --- |
| 项目编码 | 对用户决策价值低，占用列宽 | 项目查看页、编辑页 |
| 默认站点地址 | 内容较长，容易撑开表格 | 项目查看页、编辑页 |
| 默认环境 | 第一版环境配置较轻，不作为筛选条件 | 项目查看页、编辑页 |
| 负责人 | 第一版权限已简化，负责人不是核心流转条件 | 项目查看页 |
| 最近任务 | 信息量大且动态变化快 | 项目查看页的最近任务区 |
| 待处理事项 | 需要按类型和优先级展示 | 项目查看页的待处理事项区 |
| 最近报告 | 需要展示运行结果和报告入口 | 项目查看页的最近报告区 |

### 5.2 筛选

第一版只支持按项目名称筛选。

筛选规则：

- 搜索框占位文案：`搜索项目名称`
- 支持项目名称模糊搜索
- 不提供状态、负责人、是否有知识库、是否有待处理事项等筛选条件
- 已归档项目默认不在列表中展示；如后续需要查看归档项目，可在项目详情入口或归档管理中扩展，不作为第一版列表筛选项

### 5.3 权限

- 管理员看到全部项目。
- 访客看到全部项目，但所有写操作不可用。
- 测试工程师只看到分配给自己的项目。

### 5.4 操作

| 操作 | 管理员 | 测试工程师 | 访客 | 说明 |
| --- | --- | --- | --- | --- |
| 查看 | 可用 | 仅分配项目可用 | 可用 | 进入项目查看页，展示项目信息、统计信息、最近任务、待处理事项、最近报告 |
| 编辑 | 可用 | 不可用 | 不可用 | 编辑创建项目时填写的全部信息，包括名称、编码、描述、默认站点、默认环境、负责人、成员分配等 |

列表中的统计数字可以点击跳转：

- 需求文档数量：跳转到当前项目的需求列表。
- 知识库版本：跳转到当前项目的知识库首页。
- 测试用例数量：跳转到当前项目的测试用例列表。
- UI 自动化用例数量：跳转到当前项目的 UI 自动化列表。

## 6. 项目详情

项目详情是项目内工作的入口，也是项目列表中不适合展示的信息承载页。

### 6.1 页面区域

- 项目基本信息
- 项目资产统计
- 最近任务
- 待处理事项
- 最近执行报告
- 项目模块入口

### 6.2 项目查看页

点击“查看”进入项目查看页，页面只读展示：

- 项目基本信息：项目名称、项目编码、描述、默认站点地址、默认环境、负责人、创建时间、更新时间。
- 项目成员：测试工程师列表和数量。
- 项目资产统计：需求文档数量、知识库版本、测试用例数量、UI 自动化用例数量。
- 最近任务：最近的需求分析、站点探索、知识库生成、用例生成、UI 自动化执行任务。
- 待处理事项：待回答澄清问题、待评审用例、知识库待更新、失败待诊断、自愈待确认。
- 最近报告：最近 UI 自动化执行记录和 Allure 报告入口。
- 模块入口：需求、探索、知识库、测试用例、UI 自动化、报告中心。

项目查看页不再单独展示“项目状态”。如果项目已归档，只在页面顶部展示“已归档”提示，并禁用新增和执行类操作。

### 6.3 项目内模块入口

- 需求分析
- 站点探索
- 项目知识库
- 测试用例
- UI 自动化
- 接口自动化 Soon
- 执行记录
- 项目设置

---

## 7. 项目归档

归档规则：

- 归档项目仍可查看。
- 归档项目不能新建需求分析、站点探索、知识库更新、测试用例生成、UI 自动化执行任务。
- 归档项目的历史报告、知识库版本、测试用例和 UI 自动化代码仍可查看。
- 管理员可以恢复归档项目。

---

## 8. SQLite 存储策略

SQLite 保存：

- 项目元数据
- 项目成员关系
- 项目归档时间
- 项目统计缓存，第一版可实时查询，后续再缓存

文件系统保存：

- 项目下上传文件
- 知识库 Markdown
- UI 自动化代码
- 执行报告和附件

---

## 9. 验收标准

- 管理员可以创建、编辑、归档、恢复项目。
- 项目编码唯一。
- 项目列表只支持按项目名称筛选。
- 项目列表必须展示描述、测试工程师数量、需求文档数量、知识库版本、测试用例数量、UI 自动化用例数量和操作列。
- 项目列表操作包含查看和编辑；编辑仅管理员可用，查看按角色权限可用。
- 项目查看页必须展示项目基本信息、统计信息、最近任务、待处理事项和最近报告。
- 第一版不展示复杂项目状态，只对已归档项目展示归档标签和禁用新增任务。
- 测试工程师只能看到被分配项目。
- 访客可以查看全部项目但不能编辑。
- 项目归档后禁止新建任务。
- 项目详情能跳转到需求、探索、知识库、测试用例、UI 自动化、接口自动化 Soon 和报告。
