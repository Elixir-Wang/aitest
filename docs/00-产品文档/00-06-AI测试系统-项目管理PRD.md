# 00-06 AI测试系统 - 项目管理 PRD

## 1. 这份文档解决什么问题

本文只细化项目管理。项目是 AI 测试系统第一业务边界，需求文档、站点探索、知识库、测试用例、UI 自动化代码、执行记录和报告都必须归属于项目；接口自动化第一期只预留入口，不产生项目资产。

权限管理见：

- `00-02-AI测试系统-权限管理PRD.md`

控制台见：

- `00-07-AI测试系统-控制台PRD.md`

---

## 2. 项目边界

### 2.1 项目负责隔离

- 源文档
- 需求分析
- 澄清问题
- 站点探索
- 知识库
- 测试用例
- UI 自动化测试代码
- 执行记录
- Allure 报告索引
- 失败诊断和自愈记录

### 2.2 项目不负责

- 不负责系统级模型 Provider 配置
- 不负责全局用户管理
- 不负责跨项目共享知识库，第一版不做

---

## 3. 项目字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 项目名称 | 是 | 页面展示名称 |
| 项目编码 | 是 | 项目内唯一编码，用于目录和任务归属 |
| 项目描述 | 否 | 测试项目背景 |
| 项目状态 | 是 | 启用、归档 |
| 默认站点地址 | 否 | 后续站点探索默认地址 |
| 默认环境 | 否 | 本地、测试、预发、生产等文本值 |
| 负责人 | 否 | 管理员或测试工程师 |
| 创建时间 | 是 | 系统生成 |
| 更新时间 | 是 | 系统生成 |

---

## 4. 项目动作

| 动作 | 管理员 | 测试工程师 | 访客 |
| --- | --- | --- | --- |
| 创建项目 | 可执行 | 不可执行 | 不可执行 |
| 编辑项目 | 可执行 | 不可执行 | 不可执行 |
| 分配测试工程师 | 可执行 | 不可执行 | 不可执行 |
| 查看项目 | 可查看全部 | 仅分配项目 | 可查看全部 |
| 归档项目 | 可执行 | 不可执行 | 不可执行 |
| 恢复项目 | 可执行 | 不可执行 | 不可执行 |

第一版不做物理删除，避免误删测试资产。

---

## 5. 项目列表

### 5.1 列表字段

- 项目名称
- 项目编码
- 状态
- 负责人
- 测试工程师数量
- 需求文档数量
- 知识库版本
- 测试用例数量
- UI 自动化用例数量
- 最近更新时间

### 5.2 筛选

- 状态
- 负责人
- 关键词
- 是否有知识库
- 是否有待处理事项

### 5.3 权限

- 管理员看到全部项目。
- 访客看到全部项目，但所有写操作不可用。
- 测试工程师只看到分配给自己的项目。

---

## 6. 项目详情

项目详情是项目内工作的入口。

### 6.1 页面区域

- 项目基本信息
- 项目资产统计
- 最近任务
- 待处理事项
- 最近执行报告
- 项目模块入口

### 6.2 项目内模块入口

- 需求分析
- 站点探索
- 项目知识库
- 测试用例
- UI 自动化
- 接口自动化 Soon
- 执行记录
- 项目设置

---

## 7. 项目归档

归档规则：

- 归档项目仍可查看。
- 归档项目不能新建需求分析、站点探索、知识库更新、测试用例生成、UI 自动化执行任务。
- 归档项目的历史报告、知识库版本、测试用例和 UI 自动化代码仍可查看。
- 管理员可以恢复归档项目。

---

## 8. SQLite 存储策略

SQLite 保存：

- 项目元数据
- 项目成员关系
- 项目状态
- 项目统计缓存，第一版可实时查询，后续再缓存

文件系统保存：

- 项目下上传文件
- 知识库 Markdown
- UI 自动化代码
- 执行报告和附件

---

## 9. 验收标准

- 管理员可以创建、编辑、归档、恢复项目。
- 项目编码唯一。
- 测试工程师只能看到被分配项目。
- 访客可以查看全部项目但不能编辑。
- 项目归档后禁止新建任务。
- 项目详情能跳转到需求、探索、知识库、测试用例、UI 自动化、接口自动化 Soon 和报告。
