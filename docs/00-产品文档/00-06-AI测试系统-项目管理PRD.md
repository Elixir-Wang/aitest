# 00-06 AI测试系统 - 项目管理 PRD

## 1. 这份文档解决什么问题

本文只细化项目管理。项目是 AI 测试系统第一业务边界，需求文档、站点探索、知识库、测试用例、UI 自动化代码、执行记录和报告都必须归属于项目；接口自动化第一期只预留入口，不产生项目资产。

权限管理见：

- `00-02-AI测试系统-权限管理PRD.md`

控制台见：

- `00-07-AI测试系统-控制台PRD.md`

---

## 2. 项目边界

### 2.1 项目负责隔离

- 源文档
- 需求分析
- 澄清问题
- 站点探索
- 知识库
- 测试用例
- UI 自动化测试代码
- 执行记录
- Allure 报告索引
- 失败诊断和自愈记录

### 2.2 项目不负责

- 不负责系统级模型 Provider 配置
- 不负责全局用户管理
- 不负责跨项目共享知识库，第一版不做

---

## 3. 项目字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 项目名称 | 是 | 页面展示名称 |
| 项目描述 | 否 | 测试项目背景，在项目列表中展示为描述列 |
| 项目状态 | 是 | `active` 或 `archived`，页面展示为“活跃”或“归档” |
| 创建时间 | 是 | 系统生成 |
| 更新时间 | 是 | 系统生成 |

当前版本只保留简单项目状态表达生命周期：正常项目展示“活跃”标签，归档项目展示“归档”标签。归档状态可通过编辑项目状态修改。

---

## 4. 项目动作

| 动作 | 管理员 | 测试工程师 | 访客 |
| --- | --- | --- | --- |
| 创建项目 | 可执行 | 不可执行 | 不可执行 |
| 编辑项目 | 可执行 | 不可执行 | 不可执行 |
| 查看项目 | 可查看全部 | 仅分配项目 | 可查看全部 |
| 删除项目 | 可执行 | 不可执行 | 不可执行 |

当前实现支持管理员删除项目，后端提供 `DELETE /projects/{project_id}`。

---

## 5. 项目列表

项目列表负责让用户快速找到项目，并进入项目详情。复杂信息不堆在列表列中。

### 5.1 列表字段

当前项目列表已实现字段：

- 项目名称
- 描述
- 状态
- 最近更新时间
- 操作

列表字段说明：

| 字段 | 展示规则 |
| --- | --- |
| 项目名称 | 主标题；如果项目已归档，在名称旁展示“已归档”标签 |
| 描述 | 展示项目描述，超长省略，悬停或详情中查看完整内容 |
| 状态 | 活跃或归档 |
| 最近更新时间 | 项目最近更新时间 |
| 操作 | 概览、编辑、删除 |

### 5.2 筛选

当前实现为前端本地搜索，覆盖项目名称、描述、状态和更新时间。

筛选规则：

- 支持项目名称、描述、状态和更新时间本地模糊搜索。
- 不提供其他筛选条件。

### 5.3 权限

- 管理员看到全部项目。
- 访客看到全部项目，但所有写操作不可用。
- 测试工程师只看到分配给自己的项目。

### 5.4 操作

| 操作 | 管理员 | 测试工程师 | 访客 | 说明 |
| --- | --- | --- | --- | --- |
| 概览 | 可用 | 仅分配项目可用 | 可用 | 进入项目查看页，展示项目信息和项目模块入口 |
| 编辑 | 可用 | 不可用 | 不可用 | 编辑项目名称、描述和状态 |
| 删除 | 可用 | 不可用 | 不可用 | 删除项目 |

## 6. 项目详情

项目详情是项目内工作的入口，也是项目列表中不适合展示的信息承载页。

### 6.1 页面区域

- 项目基本信息
- 项目模块入口

### 6.2 项目查看页

点击“查看”进入项目查看页，页面只读展示：

- 当前已实现：项目名称、描述、状态、创建时间、更新时间和模块入口。
- 当前后续补充项：最近任务、待处理事项、最近报告。当前页面已有占位，后续需要接入真实数据。

项目查看页不再单独展示“项目状态”。如果项目已归档，只在页面顶部展示“已归档”提示，并禁用新增和执行类操作。

### 6.3 项目内模块入口

- 需求分析
- 站点探索
- 项目知识库
- 测试用例
- UI 自动化
- 接口自动化 Soon
- 执行记录
- 项目设置

---

## 7. 项目归档

归档规则：

- 归档项目仍可查看。
- 后续补充项：归档项目不能新建需求分析、站点探索、知识库更新、测试用例生成、UI 自动化执行任务。
- 归档项目的历史报告、知识库、测试用例和 UI 自动化代码仍可查看。

---

## 8. SQLite 存储策略

SQLite 保存：

- 项目元数据
- 项目状态

文件系统保存：

- 项目下上传文件
- 知识库 Markdown
- UI 自动化代码
- 执行报告和附件

---

## 9. 验收标准

当前已实现：

- 管理员可以创建、编辑、删除项目。
- 项目列表展示项目名称、描述、状态、最近更新时间和操作列。
- 项目列表支持本地搜索项目名称、描述、状态和更新时间。
- 项目列表操作包含概览、编辑、删除；编辑和删除仅管理员可用。
- 测试工程师只能看到通过 `project_scope` 分配给自己的项目；访客可以查看全部项目但不能编辑。
- 项目详情能跳转到需求、探索、知识库、测试用例、UI 自动化、接口自动化 Soon 和项目设置。

后续补充项：

- 项目详情页接入最近任务、待处理事项、最近报告真实数据。
- 归档项目禁止新建需求分析、站点探索、知识库更新、测试用例生成、UI 自动化执行任务。
