# 错误处理策略

**日期**: 2026-06-26  
**核心**: 分类处理，智能重试

---

## 🎯 错误分类和重试策略

### 1. 定位器错误

| 错误类型 | 重试次数 | 策略 |
|---------|---------|------|
| 定位器不唯一 | 0 | Agent优化定位器 |
| 元素未找到 | 1 | 可能加载慢，等待2秒重试 |
| 元素不可见 | 1 | 滚动后重试 |

### 2. 页面加载错误

| 错误类型 | 重试次数 | 策略 |
|---------|---------|------|
| 页面加载超时 | 2 | 网络不稳定，等待3秒重试 |
| 404错误 | 0 | 不重试 |
| 500错误 | 1 | 服务器问题，等待5秒重试 |

### 3. Agent错误

| 错误类型 | 重试次数 | 策略 |
|---------|---------|------|
| Agent决策失败 | 3 | LLM故障，等待2秒重试 |
| Token超限 | 1 | 简化快照重试 |

### 4. 网络错误

| 错误类型 | 重试次数 | 策略 |
|---------|---------|------|
| 连接超时 | 3 | 等待5秒重试 |
| 连接中断 | 2 | 等待3秒重试 |

### 5. Playwright错误

| 错误类型 | 重试次数 | 策略 |
|---------|---------|------|
| Playwright崩溃 | 1 | 重启进程重试 |

---

## 🚨 致命错误（立即终止）

不重试，直接终止：
- 认证失败
- 权限不足（403）
- Playwright无法启动
- 配置错误

## 📊 错误计数

```python
class ErrorHandler:
    def __init__(self):
        self.consecutive_failures = 0
        self.total_failures = 0
        self.max_consecutive = 3
        self.max_total = 10
    
    def should_terminate(self):
        return (
            self.consecutive_failures >= self.max_consecutive or
            self.total_failures >= self.max_total
        )
```

## ✅ 错误记录

所有错误记录到logs/errors.yaml，包含：
- 错误类型
- 页面URL
- 定位器
- 重试次数
- 解决方式
