# 测试点公开 ID 移除设计

## 目标
- 详情弹窗将标题放在优先级和类型徽章之后。
- 前端不展示或声明 `point_key`。
- 后端公开响应不返回 `point_key`。
- 后端 Markdown、数据库唯一约束、ID 复用和测试用例生成继续使用内部 `point_key`。

## 边界
`point_key` 是内部稳定身份，不进行数据库迁移，不修改生成协议，不影响 Markdown 编辑格式。公开响应通过序列化边界移除该字段。

## 验证
- 前端契约测试验证标题与徽章同排、无 ID 文案、API 类型无字段。
- 后端服务测试验证 overview/save 响应无字段，同时数据库中的稳定 key 和原 ID 仍被复用。
