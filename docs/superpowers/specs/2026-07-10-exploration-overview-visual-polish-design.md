# 探索概览视觉优化设计

## 目标

在不修改探索数据契约和交互行为的前提下，提升探索概览的信息层级与执行过程可读性。

## 设计

- 移除概览区域最外层卡片，页面只保留“执行步骤”和“探索输出”两个主面板。
- 左侧步骤用连续状态轨迹表达执行顺序；完成、失败、进行中和待执行继续复用现有状态色。
- 当前或失败步骤使用轻量状态底色，其他步骤保持克制的白色表面。
- 右侧 Agent 消息使用机器人图标和强调色名称，工具调用保持缩进并增加轨迹线。
- 面板标题增加语义图标，步骤数量进入标题栏。
- 继续复用 Tailwind、现有主题 token 和 lucide-react，不新增依赖或数据字段。

## 验证

- 契约测试确认外层容器扁平化、步骤轨迹和 Agent/工具轨迹样式存在。
- 运行前端 lint/type check 或项目已有等价验证。
- 在桌面与移动视口检查布局、滚动和文本溢出。
