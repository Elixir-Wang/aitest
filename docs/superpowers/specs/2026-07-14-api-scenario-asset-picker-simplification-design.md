# 场景接口选择弹窗简化设计

## 背景

当前“从接口资产添加步骤”弹窗包含接口文档侧栏、常用标签、接口列表和详情预览三栏。场景编排的实际目标仅是选择接口，现有界面信息过多、视觉拥挤，并且与项目已有“接口资产”分组列表风格不一致。

## 目标

- 将弹窗简化为单栏接口选择器。
- 复用“接口资产”页面的分组、折叠、数量徽标和接口行视觉语言。
- 支持按分组批量选择，也支持逐个选择接口。
- 保留接口被选择的先后顺序，按该顺序添加到执行链路。

## 界面结构

弹窗采用约 720px 的桌面宽度和不超过 80vh 的高度，结构如下：

1. 标题区：标题“从接口资产添加步骤”和简短说明。
2. 搜索区：仅保留“搜索接口名称或路径”输入框。
3. 接口列表：按接口第一个标签分组，无标签时归入“未分组”。
4. 操作区：左侧显示已选择数量，右侧显示“取消”和“添加到链路”。

不再展示接口文档侧栏、常用标签、方法筛选器和接口详情预览。

## 分组交互

- 分组标题行包含复选框、展开箭头、分组名称和接口数量。
- 点击展开区域可展开或折叠分组。
- 点击分组复选框可选择或取消该分组中的全部接口。
- 分组内部分接口被选择时，分组复选框显示半选状态。
- 搜索时仅展示包含匹配接口的分组，并自动展开这些分组。
- 无搜索条件时，分组默认折叠，减少首屏信息密度。

## 接口行

- 每行包含复选框、HTTP 方法徽标、接口名称和接口路径。
- 点击接口行可切换该接口的选择状态。
- 接口名称与路径过长时截断，并通过 `title` 提供完整内容。
- 已选接口行使用轻量的蓝色背景和边框反馈。

## 选择规则

- 单个选择按用户操作顺序追加到选择数组。
- 分组全选时，按分组内当前展示顺序追加尚未选择的接口。
- 取消选择时从选择数组中移除对应接口，不改变其余接口顺序。
- 点击“添加到链路”后提交接口 ID 数组、清空本次选择并关闭弹窗。
- 点击“取消”或关闭弹窗时清空本次选择和搜索条件。

## 空状态

- 没有任何接口资产时显示“暂无可选接口资产”。
- 搜索没有结果时显示“未找到匹配接口”。

## 验收标准

- 弹窗只展示与接口选择直接相关的信息。
- 分组样式与现有“接口资产”列表保持一致。
- 分组全选、半选、逐个选择和取消选择行为正确。
- 搜索结果自动展开，且可以按名称、路径、方法和标签匹配。
- 提交的接口 ID 顺序与用户选择顺序一致。
- 弹窗在常见桌面尺寸下无横向裁切，列表区域可独立滚动。
