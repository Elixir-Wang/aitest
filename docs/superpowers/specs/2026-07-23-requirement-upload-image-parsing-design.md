# 需求上传图片解析展示设计

## 目标

在需求上传页面的“上传文件”区域上方展示“图片解析”选项，让用户知道该能力正在规划中，同时避免用户选择尚未支持的功能。

## 交互设计

- 字段名称为“图片解析”。
- 使用与页面现有上传模式一致的单选项视觉样式。
- “否”默认选中并保持可用。
- “是”置灰且不可选择，旁边展示“暂不支持”。
- 该配置只用于前端展示，不需要悬停提示或额外弹窗。

## 实现范围

- 修改 `apps/frontend/src/components/ai-testing/requirement-upload-page.tsx`。
- 将“图片解析”放在需求名称或已有需求选择区域之后、“上传文件”之前。
- 不新增 React 状态；单选组使用固定值“否”。
- 不修改上传请求，不新增表单字段或接口参数。
- 不修改现有表单校验、文件类型限制和提交流程。

## 验收标准

- 页面加载后“图片解析”的“否”默认选中。
- “是”显示为禁用状态，用户无法选中。
- “是”旁明确显示“暂不支持”。
- 上传文件及提交行为与修改前保持一致。
