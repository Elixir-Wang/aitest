# API 响应示例展示设计

## 目标

在接口详情的“响应信息”中展示 OpenAPI 定义的响应示例，同时保留现有响应字段表。

## 范围

- 仅修改接口自动化页面的响应详情展示。
- 不修改 OpenAPI 解析器、数据库结构、后端 API 或请求调试预填逻辑。
- 不处理现有的响应状态码切换测试与实现不一致问题。

## 数据优先级

对于每个响应状态码和媒体类型，按以下顺序解析可展示示例：

1. `content.examples`：遍历具名示例，使用条目的 `value`；标题优先使用 `summary`，其次使用示例名称。
2. `content.example`：作为单个示例。
3. `content.schema.example`：作为单个示例。
4. `exampleFromSchema(content.schema)`：只在以上字段均不存在时生成兜底值。

空对象、空数组、空字符串和 `null` 均为合法 OpenAPI 示例值，必须被展示；是否存在示例只通过字段是否为 `undefined` 判断。

## 界面

- 每个响应状态码卡片继续显示状态码、描述、媒体类型和字段表。
- 在字段表下方新增“示例信息”区域。
- 每条示例显示可选标题和格式化 JSON 代码块；代码块使用等宽字体、保留换行并限制最大高度，超出时可滚动。
- 没有字段表时，示例区域仍可单独展示。

## 验证

- 使用现有 Node 源码契约测试，验证响应组件读取 `examples`、`example` 与 Schema 兜底逻辑。
- 运行相关前端测试和 Biome 检查。
