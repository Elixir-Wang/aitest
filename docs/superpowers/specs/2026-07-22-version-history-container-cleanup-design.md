# 版本记录区域外观精简设计

## 背景

需求文档详情页的“版本记录”标签已经通过顶部标签明确当前区域，内容区再次展示“版本记录”标题并使用 `ShellSection` 外框，形成重复标题和多余的外层圆角边框。

## 目标

- 删除版本记录内容区内重复的“版本记录”标题。
- 删除包裹整个版本表格的外层 `ShellSection` 框。
- 保留版本表格自身的边框、圆角、表头、行分隔和现有交互。

## 实现方案

在需求文档详情页的 `versions` 标签内容中移除 `ShellSection` 包裹和标题节点，让错误提示或版本表格直接作为 `TabsContent` 的内容渲染。

## 非目标

- 不修改顶部“版本记录”标签。
- 不修改版本数据请求、加载逻辑和错误处理。
- 不修改表格列、版本链接、生效标记、时间和查看操作。
- 不修改独立版本详情页或其他版本记录组件。

## 验证

- 版本记录标签页不再显示内容区标题。
- 表格外不再出现第二层大圆角边框。
- 表格自身边框和各列内容保持正常。
- 错误状态仍能正常展示。
