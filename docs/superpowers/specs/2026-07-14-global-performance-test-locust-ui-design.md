# 全局性能测试创建与 Locust 原生 UI 设计

**日期：** 2026-07-14  
**状态：** 已确认，待实施计划  
**适用模块：** 性能测试  
**关联设计：** `2026-07-13-locust-performance-testing-module-design.md`

## 1. 背景

当前性能测试模块已经具备项目级任务列表、项目级新建页面、接口与环境复用、基础 Locust 参数、脚本审核和运行工作台。

本次设计调整第一版产品方向：

1. 从全局性能测试列表直接进入独立新建页面。
2. 在页面内依次选择项目、环境和单个接口。
3. 支持固定、手动梯度、压力、峰值和耐久五种测试模式。
4. 使用统一阶段模型生成 Locust `LoadTestShape`。
5. 平台不重复实现 Locust 已有的实时统计和运行控制界面。
6. 脚本审核完成后启动并打开 Locust 原生 Web UI。

本设计是现有性能测试设计的增量调整。与本文冲突的创建页、负载配置和运行展示设计，以本文为准。

## 2. 设计目标

- 用户无需先进入项目即可新建性能测试。
- 项目、环境、接口和请求资产保持严格项目隔离。
- 平台负责业务资产配置、复杂负载 Shape、脚本生成、安全校验和运行审计。
- Locust 原生 UI 负责其已有的启动、停止、固定负载参数、实时统计、图表和结果下载能力。
- 所有非固定负载模式复用同一种阶段数据结构和脚本执行逻辑。
- 第一版不重复建设平台侧实时运行工作台。

## 3. 范围

### 3.1 包含范围

- 全局新建性能测试入口。
- 项目、环境、单接口联动选择。
- OpenAPI 或已有接口测试用例作为请求来源。
- Path、Query、Header、Body 和成功规则编辑。
- 固定数据、JSON 数据列表和 CSV 数据文件。
- 顺序循环和随机选择两种取值策略。
- 固定、手动梯度、压力、峰值和耐久五种测试模式。
- 统一负载阶段模型。
- 性能目标和失败率安全熔断。
- Locust 脚本生成、校验、版本审核和确认。
- 每次运行独立 Locust Web 实例。
- 带平台权限校验的 Locust UI 反向代理。
- Locust 原生启动、停止、重启、统计和下载能力。
- 运行尝试、实际参数、脚本版本和操作日志记录。

### 3.2 不包含范围

- 多接口权重压测。
- 业务场景编排和接口间参数关联。
- 任意 Python 或自定义 `LoadTestShape` 代码编辑。
- 平台侧实时统计、实时图表、失败和异常工作台。
- 平台侧负载曲线预览。
- 分布式 Locust master/worker。
- 自动寻找无限制系统崩溃点。
- 第一版中的运行预约和周期调度。

## 4. 页面入口与路由

新增全局路由：

```text
/performance-tests/new
```

全局性能测试列表中的“新建性能测试”直接进入该路由，不要求用户先选择项目。

项目级入口可以继续保留，但最终统一跳转到全局新建页，并通过查询参数预选项目：

```text
/performance-tests/new?projectId={projectId}
```

查询参数只用于预选，后端仍必须校验当前用户的项目权限。

## 5. 页面布局

创建页面使用全宽表单，不使用右侧实时预览栏。

页面结构：

```text
新建性能测试
--------------------------------------------------
左侧章节导航 | 基础信息
             | 请求配置
             | 测试数据
             | 负载配置
             | 性能目标
             | 安全熔断
--------------------------------------------------
取消                         保存并生成 Locust 脚本
```

左侧章节导航只负责页面锚点定位。窄屏下导航折叠为顶部章节选择，不保留双栏工作台。

页面不展示：

- 负载曲线。
- 最大并发摘要。
- 预计运行时间摘要。
- Locust 实时统计。
- Locust 图表、失败和异常。

## 6. 基础信息与联动

基础字段：

- 测试名称。
- 项目。
- 环境。
- 接口。
- 来源接口测试用例，可选。
- 测试模式。
- 描述，可选。

联动顺序：

```text
项目 → 环境 → 接口 → 来源接口测试用例
```

交互规则：

1. 选择项目后加载该项目的环境和接口。
2. 切换项目时清空环境、接口、来源用例、请求配置和测试数据。
3. 选择接口后请求后端生成请求预览。
4. 来源用例只能选择当前项目、当前接口下的用例。
5. 用户已编辑请求内容时，切换接口或来源用例必须确认是否重置。
6. 环境认证和 Secret 只在执行侧注入，不进入可见前端状态。

## 7. 请求配置

默认请求内容来自以下来源，优先级从高到低：

1. 用户选择的已有接口测试用例。
2. OpenAPI 示例。
3. OpenAPI 默认值。
4. 按字段类型生成的安全占位值。

用户可以编辑：

- Path 参数。
- Query 参数。
- 非敏感 Headers。
- Request Body。
- 成功状态码。
- JSONPath 存在断言。
- JSONPath 等值断言。

敏感 Header 和环境认证值不得返回前端、写入任务定义或发送给脚本生成模型。

## 8. 测试数据

第一版支持三种数据来源：

### 8.1 固定数据

所有虚拟用户重复使用当前请求配置。

### 8.2 JSON 数据列表

用户提供 JSON 对象数组。每个对象作为一次参数化请求的数据源。

### 8.3 CSV 文件

用户上传 CSV 文件，首行为字段名。平台保存文件版本、摘要、行数和字段名，不在任务定义中复制完整数据。

取值策略：

- `sequential_loop`：按顺序循环读取。
- `random`：每次随机选择。

第一版不支持数据唯一消费、跨用户锁、表达式语言、任意前置脚本和外部数据生成器。

## 9. 测试模式

### 9.1 固定负载

平台不配置用户数、启动速率和运行时间，也不生成自定义 `LoadTestShape`。

用户在 Locust 原生 UI 中填写固定负载参数并启动测试。

### 9.2 手动梯度

用户逐行配置目标用户数、启动速率和保持时长。阶段按顺序连续加压，第一版不允许目标用户数下降。

### 9.3 压力测试

系统根据以下输入生成递增阶段模板：

- 起始用户数。
- 每阶段增量。
- 阶段数量。
- 启动速率。
- 每阶段保持时长。

模板生成后转换为普通阶段列表，允许用户继续手动修改。

### 9.4 峰值测试

系统默认生成：

```text
正常负载 → 突发峰值 → 恢复至正常负载
```

峰值测试是第一版唯一允许目标用户数下降的模式。

### 9.5 耐久测试

用户配置目标用户数、启动速率和长时间保持时长。平台提示耐久测试通常需要较长运行时间，但不强制最小时长。

## 10. 统一阶段模型

除固定负载外，其他模式最终转换为统一阶段列表：

```typescript
type LoadStage = {
  id: string;
  name: string;
  targetUsers: number;
  spawnRate: number;
  holdSeconds: number;
  order: number;
};
```

阶段表格字段：

```text
阶段名称 | 目标用户数 | 启动速率 | 保持时长 | 排序 | 删除
```

校验规则：

- 阶段名称必填且在任务内唯一。
- 目标用户数必须为正整数。
- 启动速率必须大于零。
- 保持时长必须为正整数。
- 至少存在一个阶段。
- 手动梯度、压力和耐久模式的目标用户数不得下降。
- 峰值模式必须包含正常、峰值和恢复三个语义阶段，且峰值用户数高于正常用户数。
- 阶段顺序以 `order` 为准，拖动排序后重新编号。

后端根据该列表确定性生成受控 `LoadTestShape`，不得让模型输出任意 Shape 代码。

## 11. 性能目标

可选指标：

- 最大失败率。
- 最大平均响应时间。
- 最大 P95 响应时间。
- 最低平均 RPS。

这些指标主要用于运行结束后的结果判定，不因单次瞬时波动立即停止测试。

## 12. 安全熔断

安全熔断与性能目标分离，第一版只基于严重失败率超标自动停止：

- 检测窗口秒数。
- 最大允许失败率。
- 连续超标次数。
- 是否启用自动停止。

熔断由平台运行监控执行，Locust UI 中的操作不能关闭或绕过已启用的环境保护规则。

熔断后平台必须：

1. 请求 Locust 停止当前运行。
2. 保存触发时间、窗口数据和阈值。
3. 将运行尝试标记为 `circuit_broken`。
4. 写入操作日志和运行事件。

## 13. 创建与脚本审核

创建流程：

```text
填写任务配置
→ 保存任务定义
→ 生成结构化 LocustScriptPlan
→ 确定性渲染 locustfile.py
→ 执行结构、语法、导入和安全校验
→ 用户审核并确认脚本版本
```

创建页按钮：

```text
取消 | 保存并生成 Locust 脚本
```

脚本审核页展示：

- 只读 `locustfile.py`。
- 脚本版本。
- 来源项目、环境和接口。
- 测试模式和阶段表格。
- 数据文件摘要。
- 校验结果。
- 生成时间。

审核页操作：

```text
返回修改 | 重新生成 | 确认并启动 Locust UI
```

未经确认的脚本版本不得启动 Locust。

## 14. Locust Web UI

### 14.1 启动方式

确认脚本后，后端为本次运行启动独立 Locust Web 进程：

- 使用独立内部端口。
- 使用本次确认的不可变脚本版本。
- 使用本次环境和请求快照。
- 使用独立结果目录。
- 不将内部端口直接暴露给浏览器。

### 14.2 访问方式

平台提供带权限校验的代理地址：

```text
/api/v1/performance-test-runs/{runId}/locust-ui/{path...}
```

前端通过“打开 Locust UI”按钮在新标签页进入该地址。

代理必须处理 Locust UI 的 HTML、静态资源、HTTP API、事件流和 WebSocket 请求，并验证：

- 当前用户已登录。
- 当前用户有运行所属项目的访问权限。
- 运行存在且 Locust Web 实例可用。
- 请求目标只能是该运行登记的内部端口。

### 14.3 原生 UI 控制范围

固定负载模式：

- 用户在原生 UI 中填写用户数、启动速率和运行时间。
- 用户可以启动、停止和重新运行。

自定义 Shape 模式：

- 用户可以使用 Locust 原生 UI 提供的全部可用操作。
- 用户数和阶段由 `LoadTestShape` 控制。
- 平台不额外实现一套阶段运行控制界面。

Locust UI 中发生的启动、停止和重启必须同步回平台。

## 15. 运行尝试与状态同步

一个性能测试运行可以包含多个运行尝试。用户在 Locust UI 中重新启动时创建新的尝试记录，不覆盖历史尝试。

运行尝试至少记录：

- 运行 ID 和尝试序号。
- 脚本版本 ID。
- 测试模式。
- 实际固定负载参数或 Shape 快照。
- 开始时间和结束时间。
- `pending`、`running`、`stopped`、`completed`、`failed`、`circuit_broken` 状态。
- 操作来源：平台或 Locust UI。
- 操作用户。
- 结果目录和产物清单。
- 熔断原因，可选。

后端通过 Locust 事件、Runner 状态和进程状态同步平台状态，不依赖前端页面保持打开。

## 16. 权限与安全

- 全局新建页只展示当前用户可访问的项目。
- 环境、接口、来源用例和数据文件必须属于所选项目。
- Locust UI 代理不得接受浏览器提供的目标主机或端口。
- 每次运行只能代理到后端登记的本地 Locust 实例。
- Secret 不进入浏览器、任务定义、脚本生成模型输入和日志。
- 上传数据文件需要限制类型、大小和存储路径。
- Locust 子进程使用独立工作目录和受控环境变量。
- 运行结束或超时后关闭 Web 进程并释放端口。

## 17. 错误处理

- 项目切换失败：保留项目选择，清空下游资产并提示错误。
- 请求预览失败：保留基础信息，不允许生成脚本。
- 数据文件校验失败：指出行号或字段问题。
- 脚本生成或校验失败：保留任务定义，允许重新生成。
- Locust Web 启动失败：运行保持可重试状态，不生成伪运行记录。
- Locust UI 实例已关闭：代理返回明确的实例不可用错误。
- 内部端口冲突：后端重新分配端口，不暴露底层异常给用户。
- 平台状态与 Locust 状态短暂不一致：以后端进程和 Runner 状态为准进行最终收敛。

## 18. 验收标准

1. 用户可以从全局性能测试列表直接进入新建页面。
2. 用户可以在页面中选择项目，并只看到该项目的环境、接口和来源用例。
3. 切换项目会安全清空所有下游配置。
4. 用户可以复用并修改接口请求配置和成功规则。
5. 用户可以选择固定、JSON 列表或 CSV 测试数据。
6. 用户可以选择五种测试模式。
7. 非固定模式统一保存为阶段列表并生成受控 `LoadTestShape`。
8. 页面不展示负载曲线和运行实时统计。
9. 用户必须审核并确认脚本后才能启动 Locust UI。
10. 固定负载可以在 Locust UI 中填写原生参数并启动。
11. Shape 模式按照平台阶段配置运行。
12. 用户可以在 Locust UI 中启动、停止和重新运行。
13. Locust UI 只能通过平台鉴权代理访问。
14. Locust UI 操作和实际参数可以同步到平台运行尝试与操作日志。
15. 安全熔断能够停止严重失败的运行，并记录完整原因。

## 19. 测试边界

后端至少覆盖：

- 项目、环境、接口、来源用例和数据文件隔离。
- 五种模式到统一阶段模型的转换。
- 阶段递增和峰值回落规则。
- 固定模式不生成 `LoadTestShape`。
- Shape 模式确定性脚本渲染。
- Locust Web 端口分配、启动、停止和回收。
- 代理目标不可被请求参数篡改。
- HTML、静态资源、API、事件流和 WebSocket 代理。
- Locust UI 启停事件到运行尝试的同步。
- 安全熔断和状态收敛。

前端至少覆盖：

- 全局新建路由和列表入口。
- 项目选择与下游字段重置。
- 请求来源切换确认。
- 数据来源和取值策略提交映射。
- 五种模式的字段显示和阶段表格校验。
- 固定模式隐藏阶段表格。
- 页面不存在负载曲线和平台实时统计组件。
- 脚本未确认时不能启动 Locust UI。
- “打开 Locust UI”使用新标签页和平台代理地址。

## 20. 后续版本候选

- 多接口权重压测。
- 业务场景编排和参数关联。
- 分布式 Locust worker。
- 数据唯一消费和高级数据生成。
- 运行预约和周期调度。
- 平台统一聚合多个 Locust 实例的跨运行对比报告。
- 在严格隔离环境中开放高级自定义 Shape。
