# 接口资产位置徽章布局优化

## 目标

减少接口资产详情中字段行的重复信息和视觉拥挤，同时保留参数位置的快速识别能力。

## 设计

- 将位置徽章从字段行提升到对应分组标题后方。
- 授权区标题展示 `header`。
- 请求参数区标题展示当前分组包含的 `path`、`query`；不存在的类型不展示。
- 请求体区标题展示 `body`，并保留右侧 Content-Type。
- 响应信息区标题展示 `response`，并保留右侧状态码选择和 Content-Type。
- 字段行仅保留字段名、数据类型、必填状态、说明、示例和约束，不再重复展示位置徽章。

## 布局规则

- 位置徽章紧跟标题，形成清晰的标题级元信息。
- 状态码和 Content-Type 继续位于标题行右侧，避免与标题级位置徽章混杂。
- 标题行允许换行，保证窄屏下不发生横向溢出。
- 沿用现有 Badge、颜色和字号体系，不引入新的视觉组件。

## 数据与兼容性

- 不修改 OpenAPI 数据解析及字段行数据结构。
- 请求参数标题徽章根据实际参数位置动态生成，避免固定显示不存在的类型。
- 仅调整接口资产详情的展示层，不影响调试弹窗及其他页面。

## 验证

- 检查授权、请求参数、请求体和响应信息标题的徽章展示。
- 检查字段行不再出现 `header`、`path`、`query`、`body`、`response`。
- 检查缺少某类参数、无请求体、多响应状态和窄屏布局。
- 运行前端静态检查，并在本地页面进行视觉验证。
