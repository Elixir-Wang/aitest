# 性能测试重新压测与统计重置设计

**日期：** 2026-07-23

## 目标

- 修复终止态运行的“重置统计”按钮错误置灰问题。
- 为终止态运行提供“重新压测”入口。

## 设计

- “重置统计”的前端可用状态与后端保持一致：除 `created`、`stopping` 外均可调用；请求执行期间继续禁用。
- “重新压测”仅在 `completed`、`stopped`、`failed`、`cancelled` 状态展示。
- 点击后复用当前运行的 `script_id` 和负载配置，创建一条独立运行记录，立即启动，并跳转到新运行详情页。
- 原运行及其历史数据保留，不复用终止态运行 ID，不新增后端接口。

## 验收

- 已停止运行可点击“重置统计”。
- 终止态运行显示“重新压测”，点击后创建并启动新运行。
- 新运行启动失败时停留在当前页面并展示现有 API 错误提示。
