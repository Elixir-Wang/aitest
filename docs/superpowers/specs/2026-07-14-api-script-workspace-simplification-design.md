# 接口自动化测试脚本工作区精简设计

## 目标

精简“测试脚本”页面，只保留脚本选择、删除、运行配置展示和执行能力，完整移除脚本代码查看能力及其专用后端接口。

## 前端变更

- 删除“查看代码”按钮和脚本代码弹窗。
- 删除脚本文件预览相关状态、派生状态、加载 effect、类型和 API 客户端方法。
- 将“执行脚本”按钮移动到左侧脚本列表顶部，位于“删除”按钮右侧。
- 删除页面底部操作栏，包括环境、脚本、关联用例汇总和前置检查进度两行。
- 删除“修改环境配置”和“新建接口环境”按钮，保留运行环境选择和配置只读展示。
- 执行按钮继续使用当前选中脚本；未勾选脚本时执行当前脚本，勾选后执行勾选脚本。
- 执行就绪判断不再依赖脚本文件预览请求，改为检查脚本记录中的生成文件路径。

## 后端变更

- 删除 `GET /projects/{project_id}/api-scripts/{script_id}/files` 路由。
- 删除仅为该路由服务的 `get_api_script_files` 服务方法。
- 保留脚本生成、脚本列表、脚本详情、脚本更新、脚本删除和脚本执行能力。
- 保留 `test_file_path`、`data_file_path` 和生成文件，因为运行与删除流程仍依赖这些内容。

## 测试策略

- 先更新前端契约测试，要求代码预览入口、状态、请求和弹窗不存在，并要求执行按钮位于删除按钮之后。
- 先更新后端测试，要求文件预览服务不再作为脚本生成验收的一部分。
- 运行相关前端契约测试和后端脚本生成测试。
- 运行前端类型检查，确认删除导入与状态后无残留引用。

## 非目标

- 不修改脚本生成格式和文件目录。
- 不修改执行 API、运行记录和运行详情。
- 不删除脚本详情或脚本编辑 API。
- 不调整运行环境的数据模型和管理页面。
