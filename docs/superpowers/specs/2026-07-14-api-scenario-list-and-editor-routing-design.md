# API 场景编排列表与独立编辑页设计

## 目标

将“接口自动化 > 场景编排”从页签内的场景列表与编排器混合页面，调整为“场景列表 → 新建/编辑页面”的管理流程。列表样式复用项目列表的工具栏、表格、选择和操作菜单模式；新建与编辑使用独立路由承载完整编排能力。

## 页面与路由

| 页面 | 路由 | 职责 |
|------|------|------|
| 场景列表 | `/projects/{projectId}/automation/api` 的“场景编排”页签 | 搜索、选择、新建、进入编辑、删除场景 |
| 新建场景 | `/projects/{projectId}/automation/api/scenarios/new` | 编辑基础信息与执行步骤，首次保存时创建场景 |
| 编辑场景 | `/projects/{projectId}/automation/api/scenarios/{scenarioId}` | 加载并维护已有场景，支持校验、发布和运行 |

场景列表仍属于接口自动化工作区，不新增侧边导航入口。用户从新建或编辑页面返回时，回到接口自动化页面并激活“场景编排”页签。

## 场景列表

列表复用项目列表的 `ListToolbar`、表格、复选框、状态标签、空状态和 `RowActions` 交互。

### 工具栏

- 标题：场景列表
- 搜索占位：搜索场景名称或描述
- 主按钮：新建场景
- 批量操作：删除已选择场景

### 表格字段

| 字段 | 展示规则 |
|------|----------|
| 复选框 | 支持单选、全选和批量删除 |
| 场景名称 | 点击进入对应场景编辑页 |
| 描述 | 单行截断，完整内容通过现有溢出提示展示 |
| 步骤数 | 展示 `steps.length` |
| 状态 | 草稿显示“未发布”，已发布显示“已发布 vN”，归档显示“已归档” |
| 更新时间 | 使用项目现有日期时间格式化方法 |
| 操作 | 编辑、删除 |

搜索在前端按场景名称和描述过滤。删除继续调用现有场景删除接口；批量删除按选中 ID 逐个执行，全部完成后刷新列表并提示结果。

## 新建场景页

新建页不在进入页面时创建空场景，避免用户直接离开后留下无效数据。

- 页面初始使用空白草稿状态。
- 用户可填写场景名称、描述、场景变量并添加、排序、删除执行步骤。
- 首次点击“保存”时，先调用创建场景接口，再调用步骤替换接口。
- 创建成功后使用 `router.replace` 切换到该场景的编辑路由，后续保存走更新逻辑。
- 未创建前禁用校验、发布和运行；保存成功后启用。
- 场景名称为空时阻止保存并提示用户填写名称。

## 编辑场景页

编辑页复用当前场景编排已有能力，但移除左侧场景切换栏，使页面聚焦当前场景。

### 页面结构

```text
返回场景列表                  环境选择  保存  校验  发布  运行
┌──────────────────────────┬──────────────────────────────┐
│ 执行步骤                 │ 场景配置 / 当前步骤配置      │
│ 添加、选择、排序、删除   │ 名称、变量、描述、步骤 JSON  │
└──────────────────────────┴──────────────────────────────┘
```

- 左栏展示执行步骤和“添加接口用例”入口。
- 右栏在未选择步骤时展示场景基础信息；选择步骤后继续展示步骤配置。
- 顶部保留环境选择、保存、校验、发布和运行按钮。
- 删除场景只保留在列表页，避免编辑页出现重复且高风险的删除入口。
- 场景不存在或加载失败时展示明确错误，并提供返回列表入口。

## 状态与数据复用

- 继续使用现有 `listApiAutomationScenarios`、`getApiAutomationScenario`、创建、更新、删除、替换步骤、校验、发布和执行接口，不新增后端接口。
- 从当前大型接口自动化页面中抽取场景编辑状态和事件处理，供新建页与编辑页共用。
- 列表页只维护场景列表、搜索和选择状态，不加载编排器所需的接口用例、端点和环境数据。
- 编辑器按需加载当前场景、接口用例、接口端点和运行环境，避免场景列表页承担无关请求。

## 导航与兼容

- 点击“新建场景”进入新建路由。
- 点击场景名称或操作菜单中的“编辑”进入编辑路由。
- 返回列表时使用带有场景页签标识的 URL，确保接口自动化页面恢复到“场景编排”。
- 现有其他页签及其查询参数行为保持不变。
- 不修改场景后端数据结构和发布、执行语义。

## 验收标准

1. 场景编排页签只展示场景列表，不再展示三栏编排器。
2. 列表视觉结构和操作方式与项目列表保持一致。
3. 新建场景不会在保存前产生后端记录。
4. 首次保存后 URL 切换到编辑路由，刷新页面仍能继续编辑。
5. 点击已有场景名称或编辑操作可进入独立编辑页。
6. 保存、校验、发布和运行能力在编辑页保持可用。
7. 删除和批量删除后列表正确刷新，选中状态同步清理。
8. 其他接口自动化页签不受改造影响。
