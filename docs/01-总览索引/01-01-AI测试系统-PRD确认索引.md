## 4. 已确定的关键口径

- 用户不开放注册，账号由管理员创建。
- 第一版只有管理员、测试工程师、访客三类角色。
- 数据库使用 SQLite。
- 第一版自动化只做 UI 自动化，本地运行，技术栈为 pytest + Playwright + Allure。
- 接口自动化只展示 Soon，后续预留 pytest + requests + Allure。
- 知识库使用 Karpathy llm-wiki 思路，不使用向量检索。
- 澄清内容写回需求文档 Markdown 工作稿，不覆盖原始上传文件。
- 需求文档不拆分为多个需求文件，评审时按模块评审同一份文档。
- 没有需求文档时，探索文档先生成候选需求文档，评审确认后才能作为正式需求来源。
- 探索文档不直接进入正式知识库。
- 自愈由人工在失败后手动启用，不能自动改代码。
- 第一版不接 Git 仓库，不接外部缺陷系统。
- 左侧导航只展示分组和高频一级入口，二级功能进入页面内。
