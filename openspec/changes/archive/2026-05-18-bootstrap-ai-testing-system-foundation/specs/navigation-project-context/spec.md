## ADDED Requirements

### Requirement: 左侧一级导航
系统 SHALL 在左侧导航只展示分组和一级模块，不 SHALL 常驻展示二级菜单。

#### Scenario: 展示一级导航
- **WHEN** 已登录用户进入后台
- **THEN** 左侧导航展示工作台、项目工作区、测试资产、系统管理分组和对应一级入口

#### Scenario: 接口自动化 Soon
- **WHEN** 用户查看接口自动化入口
- **THEN** 系统展示 Soon 标识，并禁止创建、生成或执行接口自动化任务

### Requirement: 页面内二级导航
系统 SHALL 使用页面内 Tabs、Segmented Control、卡片入口或面包屑承载模块内二级功能。

#### Scenario: 需求模块二级功能
- **WHEN** 用户进入需求模块
- **THEN** 页面内展示文档管理、需求评审、分析结果、澄清问题、版本记录等二级入口，而不是展开左侧菜单

#### Scenario: 简单占位模块
- **WHEN** 用户进入接口自动化 Soon 页面
- **THEN** 系统可以不展示二级 Tabs，只展示只读占位说明和禁用动作

### Requirement: 项目切换器
系统 SHALL 在项目相关页面右上角展示项目切换器，并支持“全部项目”和“指定项目”工作分区。

#### Scenario: 全局页面选择全部项目
- **WHEN** 用户在控制台、任务中心、报告中心或项目列表选择“全部项目”
- **THEN** 页面数据按用户可见项目汇总展示，且不允许直接发起项目强绑定写操作

#### Scenario: 项目强绑定页面要求指定项目
- **WHEN** 用户进入需求、探索、知识库、测试用例或 UI 自动化页面
- **THEN** 系统 MUST 要求选择指定项目后才能上传、生成、编辑、评审或执行

#### Scenario: 测试工程师项目切换范围
- **WHEN** 测试工程师打开项目切换器
- **THEN** 系统只展示该用户已分配项目

### Requirement: 项目上下文同步
系统 SHALL 保持 URL、项目切换器、页面标题和面包屑中的项目上下文一致。

#### Scenario: 从项目详情进入项目模块
- **WHEN** 用户从项目详情点击需求模块入口
- **THEN** 系统进入该项目的需求路由，并同步项目切换器为该项目

#### Scenario: 切换项目
- **WHEN** 用户在项目相关页面切换项目
- **THEN** 页面列表、统计、Tabs、面包屑和操作状态 MUST 刷新为新项目上下文
