# 新增接口自动化 AI 自由画布编排

## 背景

当前接口自动化场景编辑器以 `step_order` 驱动的线性步骤列表为主，已经支持接口请求、变量绑定、响应提取、断言、条件、等待和轮询，但复杂业务链路的依赖关系不易理解，AI 也只能生成顺序化步骤，难以表达分支、汇聚和共享输出。

成熟产品通常将自然语言规划、可视化流程图、响应数据传递和运行校验组合起来。当前项目已经具备步骤和执行能力，缺少的是可持久化的图结构、画布编辑体验以及 AI 生成场景草稿的确认流程。

## 目标

- 为接口自动化场景提供受约束的自由画布编辑体验。
- 使用 React 生态成熟画布组件 `@xyflow/react`，复用现有 React、Tailwind、Zustand 和 `@dagrejs/dagre`。
- 以节点和连线表达接口依赖、条件分支、等待/轮询和汇聚关系。
- 允许 AI 根据业务目标和当前项目接口资产生成可审阅的场景草稿。
- 保持已有线性场景可读取、可运行、可发布，并提供兼容迁移。
- 在保存、校验、发布和运行前阻止无效图结构、未配置节点和非法变量依赖。

## 非目标

- 第一版不覆盖 UI 自动化、性能测试或其他场景类型。
- 第一版不做任意循环、递归子图、跨项目接口引用或开放互联网内容直接生成可执行接口。
- 第一版不自动发布 AI 生成的场景，也不在未确认的情况下执行写操作接口。
- 不将画布组件当作执行引擎；执行语义仍由后端场景运行器负责。

## 预期收益

- 用户可以直接看懂接口之间的业务依赖，而不是靠步骤顺序猜测。
- AI 生成结果可以以图形式被逐节点审核，减少错误编排和漏断言。
- 后续可以在同一模型上扩展并行、补偿、清理和运行后修复能力。
