# 探索概览界面设计方案

## 设计概述

基于类似 Claude 的双栏布局设计，左侧显示探索任务的执行步骤（TodoList），右侧显示实时的探索文本输出信息和事件流。

## 布局结构

```
┌─────────────────────────────────────────────────────────────────┐
│                        页面标题和操作按钮                          │
├─────────────────┬───────────────────────────────────────────────┤
│                 │                                               │
│  探索计划/步骤   │           实时执行监控面板                     │
│  (左侧面板)      │           (右侧面板)                          │
│                 │                                               │
│  ┌───────────┐  │  ┌─────────────────────────────────────────┐ │
│  │ 计划概览   │  │  │ 执行阶段显示                             │ │
│  │ - 目标     │  │  │ - planning / executing / completed      │ │
│  │ - 范围     │  │  └─────────────────────────────────────────┘ │
│  │ - 策略     │  │                                               │
│  └───────────┘  │  ┌─────────────────────────────────────────┐ │
│                 │  │ 实时事件流                               │ │
│  ┌───────────┐  │  │ ┌─────────────────────────────────┐     │ │
│  │ 步骤 #1    │  │  │ │ [时间] 规划开始                  │     │ │
│  │ ✓ 已完成   │  │  │ │ [时间] 执行步骤 #1               │     │ │

│  │ 步骤 #2    │  │  │ └─────────────────────────────────┘     │ │
```

## 设计细节

### 左侧面板 - 探索计划和步骤列表

**计划概览卡片**
- 显示探索目标摘要
- 显示探索范围
- 显示执行策略
- 显示预计时长
- 显示成功标准

**步骤列表**
- 每个步骤显示为独立卡片
- 步骤编号 + 描述
- 状态图标：
  - ○ 待执行 (pending)
  - ⟳ 执行中 (running) - 带动画
  - ✓ 已完成 (completed) - 绿色
  - ✗ 失败 (failed) - 红色
  - ⊘ 已取消 (cancelled) - 灰色
  - △ 部分完成 (partial) - 黄色
- 展开/收起详情
- 显示模块名称
- 显示动作类型
- 显示目标描述

### 右侧面板 - 实时执行监控

**阶段指示器**
- 显示当前执行阶段
- planning (规划中) → executing (执行中) → completed (已完成)
- 使用进度条或状态标签

**实时事件流**
- 时间轴样式显示
- 每条事件包含：
  - 时间戳
  - 事件类型标签（规划开始、步骤开始、动作执行等）
  - 事件摘要和详情
  - 可选的额外字段（URL、元素选择器等）
- 自动滚动到最新事件
- 不同事件类型用不同颜色区分
- 支持展开查看详细信息

**可读性展示**
- 模型分析、导航、点击等动作用卡片展示
- 支持代码块显示选择器
- 支持状态标签（成功、警告、错误）

## 响应式设计

- 大屏幕（lg及以上）：双栏并排显示，左侧固定宽度约 320-380px
- 中等屏幕（md-lg）：左侧宽度缩小到 280px
- 小屏幕（sm及以下）：上下堆叠，左侧面板在上，右侧面板在下

## 交互特性

1. **实时更新**：通过 SSE 流式接收后端事件，实时更新步骤状态和事件流
2. **自动滚动**：新事件到达时自动滚动到最新位置
3. **手动刷新**：提供刷新按钮手动重新加载数据
4. **步骤展开**：点击步骤卡片可展开查看详细信息
5. **事件过滤**：可选择只显示特定类型的事件（错误、警告等）

## 视觉风格

- 遵循项目现有的设计系统
- 使用 Tailwind CSS 实用类
- 左侧面板背景：`bg-muted/20`
- 步骤卡片：`border rounded-lg bg-background`
- 事件流：`border rounded-lg bg-background`
- 状态颜色：
  - 成功：`text-green-600`
  - 警告：`text-amber-600`
  - 错误：`text-red-600`
  - 执行中：`text-blue-600`
  - 待执行：`text-muted-foreground`

## 技术实现要点

1. 使用现有的 `ExplorationMonitorState` 数据结构
2. 复用 `AgentPlan` 组件的状态显示逻辑
3. 使用 `lucide-react` 图标库
4. 实现自动滚动使用 `useEffect` + `scrollIntoView`
5. SSE 流处理已在主页面实现，直接传递数据即可
