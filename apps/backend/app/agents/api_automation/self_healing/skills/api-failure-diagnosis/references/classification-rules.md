# Classification Rules

- Import, syntax, fixture, request-builder, loader, and assertion-helper failures are test code issues.
- Invalid generated inputs or inferred expected values are test data issues.
- DNS, timeout, TLS, authentication expiry, and unavailable dependencies are environment issues.
- Explicit-contract violations and reproducible server errors are interface bugs.
- Missing or conflicting contracts are contract ambiguity.
- Use unknown when evidence is insufficient.
