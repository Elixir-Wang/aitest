# 需求检查清单

用于分类需求缺口。

## 核心质量

检查主需求来源是否包含：

- 问题陈述和业务目标
- 干系人或用户角色
- 范围和非范围
- 业务流程和主路径
- 异常路径
- 业务规则
- 校验规则
- 数据对象和字段含义
- 权限规则
- 状态流转
- 集成依赖
- 通知或消息规则
- 审计或日志要求
- 非功能需求
- 验收标准

## 六个质量属性

对主需求按六个属性评估，不要只看格式：

1. **完整性**：必要信息是否齐全，是否存在缺失细节、TBD、未识别依赖、未记录约束或假设。
2. **清晰度**：语言是否无歧义，是否避免“快速”“简单”“友好”“安全”等模糊词。
3. **一致性**：需求之间是否冲突，术语、优先级、范围和细节层级是否一致。
4. **可测试性**：是否有可观察结果、可度量验收标准、清晰通过/失败条件。
5. **可追踪性**：是否能关联业务目标、来源、设计、实现和测试。
6. **可行性**：是否能在技术、预算、排期和团队能力约束内实现。

## 单条需求检查项

对每条关键需求检查：

- 是否包含主体、动作、触发条件、输入、输出和约束。
- 是否说明背景或理由。
- 是否定义依赖和前置条件。
- 是否说明业务规则和校验规则。
- 是否覆盖正向路径、异常路径、边界场景。
- 是否定义可观察验收标准。
- 是否有唯一标识或可追踪来源。
- 是否直接支持业务目标，不是镀金需求。

## 缺口类别

`key_gaps` 使用这些类别：

- `problem_statement`
- `stakeholder`
- `scope`
- `business_rule`
- `acceptance_criteria`
- `data`
- `permission`
- `integration`
- `non_functional`
- `constraint`
- `other`

## 反模式

当以下问题影响实现或测试时，应标记：

- 模糊词：快速、简单、友好、安全、可靠
- 缺少主体：谁执行动作
- 缺少触发条件：规则什么时候生效
- 缺少输出：什么变化或变得可见
- 规则互相冲突
- 隐含依赖其他系统
- 范围无边界
- 非功能描述没有指标
- 验收标准不可观察
- 偏解决方案：描述“怎么实现”，但没有说清“要达成什么业务结果”
- 镀金：加入来源没有要求的功能
- 弱追踪性：需求与业务目标或后续验证断开

## 模糊词替换

识别到模糊词时，在需求分析报告里归类说明影响；如果需要业务裁决或具体阈值，转入待澄清。

- “用户友好”“直观”“简单” → 可用性指标、任务完成率、完成时间、错误率
- “快速”“响应快” → 响应时间、百分位、并发量、数据量、测量条件
- “安全” → 认证、授权、加密、审计、留存、告警、锁定策略
- “可扩展” → 容量、吞吐、水平扩展条件、退化比例
- “可靠” → 可用率、RTO、RPO、故障切换、恢复时间

## 文档类型侧重点

### BRD

- 业务问题和业务目标是否可度量
- 干系人和角色是否明确
- 范围内、范围外和边界是否清楚
- 商业论证、约束、假设和依赖是否记录
- 业务规则和合规要求是否明确

### SRS

- 功能需求、输入输出、错误处理和边界场景是否完整
- 非功能需求是否有可度量目标
- 系统行为、状态流转、接口和集成点是否清楚
- 是否有术语表、版本信息、引用和验证方法

### 用户故事

- 是否符合 INVEST：独立、可协商、有价值、可估算、小、可测试
- 是否包含角色、能力和业务收益
- 是否有 Given-When-Then 或等价验收标准
- 是否标明依赖、优先级和完成定义

## 成熟度等级

使用：

- `RA0`：来源不可用或为空
- `RA1`：只有宽泛意图
- `RA2`：部分需求，仍有多个重要缺口
- `RA3`：可用草稿，主流程和规则大体清晰
- `RA4`：可进入实现，仅有少量轻微缺口
- `RA5`：发布质量需求，验收和 QA 标准可追踪

成熟度理由必须引用来源中的具体证据。

## 示例

差：

```text
系统应当快速且响应灵敏。
```

好：

```text
在正常负载（最多 1,000 个并发用户）下，系统应在 2 秒内响应 95% 的用户搜索请求。
```

差：

```text
系统应发送通知。
```

好：

```text
当订单状态变为“已发货”时，系统应在 5 分钟内向用户发送邮件通知，包含订单号、新状态、物流链接和预计送达日期。
```

差：

```text
系统应当安全。
```

好：

```text
系统应强制密码复杂度、限制登录失败次数、使用 TLS 加密传输、加密静态敏感数据，并记录认证尝试审计日志。
```
