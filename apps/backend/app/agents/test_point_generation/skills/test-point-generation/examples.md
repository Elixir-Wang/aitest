## 测试点详情

### [login.task.success] 使用正确凭据登录成功

| 字段 | 内容 |
|------|------|
| 模块 | 登录 |
| 类型 | 功能 |
| 优先级 | P0 |
| 来源 | 需求规格 3.1.1 |

**描述**

验证用户使用正确账号密码登录成功后，系统正确建立会话并跳转至目标页面。

**前置条件**

- 登录服务正常运行
- 测试账号已创建且状态正常

**验证点**

- 输入正确的账号和密码 → 账号和密码输入框显示已输入内容
- 提交登录请求 → 登录成功，跳转至预期页面
- 验证会话状态 → 用户会话已建立，可访问需登录的功能

**来源引用**

- 需求规格 3.1.1

**备注**

无

### [login.task.wrong_password] 错误密码登录失败

| 字段 | 内容 |
|------|------|
| 模块 | 登录 |
| 类型 | 异常 |
| 优先级 | P0 |
| 来源 | 需求规格 3.1.1 |

**描述**

验证用户输入错误密码时，系统正确拒绝登录并给出明确提示。

**前置条件**

- 登录服务正常运行
- 测试账号存在

**验证点**

- 输入正确账号和错误密码 → 输入框显示密码已输入
- 提交登录请求 → 登录失败，显示错误提示"密码错误"
- 验证会话未建立 → 用户无法访问需登录的功能

**来源引用**

- 需求规格 3.1.1

**备注**

待确认：错误提示是否暴露密码位数或格式

### [login.boundary.empty_account] 空账号登录

| 字段 | 内容 |
|------|------|
| 模块 | 登录 |
| 类型 | 边界 |
| 优先级 | P1 |
| 来源 | 需求规格 3.1.2 |

**描述**

验证用户未输入账号密码直接提交时，系统进行客户端校验。

**前置条件**

- 登录服务正常运行

**验证点**

- 不输入账号和密码直接提交 → 显示校验提示"请输入账号"
- 仅输入账号不输入密码 → 显示校验提示"请输入密码"

**来源引用**

- 需求规格 3.1.2

**备注**

无
