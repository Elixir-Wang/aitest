# 完整登录流程测试指南

## 📋 测试说明

此测试会在**有头模式**（可见浏览器）下执行完整的登录流程，让你能够：
1. **观察协议复选框是否被正确勾选**
2. **手动输入验证码**（避免验证码识别错误）
3. **查看登录是否成功**

## 📊 测试流程

测试将按照以下步骤执行：

### 第1步：访问登录页
- 浏览器会自动打开 https://www.cybotstar.cn/login

### 第2步：分析页面元素
- 自动识别登录表单中的各个元素

### 第3步：填写账号密码
- 自动填写账号：hongbao.wang@brgroup.com
- 自动填写密码

### 第4步：定位验证码
- 自动定位验证码图片
- 保存验证码截图到 /tmp/captcha-test.png

### 第5步：等待手动输入验证码
- ⚠️ **终端会提示你输入验证码**
- 查看浏览器中的验证码图片
- 在终端输入验证码，然后按回车

### 第6步：填写验证码
- 自动将你输入的验证码填入表单

### 第7步：勾选协议（重点）
- ⭐ **使用修复后的逻辑勾选协议**
- 协议区域会高亮显示（黄色边框）
- 检查复选框是否真的被勾选

### 第8步：提交登录
- 3秒倒计时后自动点击登录按钮

### 第9步：检查结果
- 检查页面URL是否改变
- 查找页面中的错误消息
- 判断登录是否成功

### 第10步：保持浏览器打开
- 浏览器保持打开60秒
- 你可以手动检查最终状态

## 🔍 观察重点

运行测试时，请注意观察：

1. **协议复选框**：
   - 是否出现黄色边框（表示协议区域被定位）
   - 复选框是否从空白变为勾选状态
   - 终端输出的复选框class是否包含 "checked"

2. **登录结果**：
   - 提交后是否离开了登录页
   - 是否有错误提示
   - URL是否变化

3. **截图文件**：
   - `/tmp/captcha-test.png` - 验证码图片
   - `/tmp/after-submit.png` - 提交后的页面截图

## ❓ 常见问题

### Q1: 为什么需要手动输入验证码？
A: 避免验证码识别错误导致的登录失败，专注测试协议勾选逻辑。

### Q2: 如果登录失败怎么办？
A: 查看终端输出的错误消息，检查：
- 账号密码是否正确
- 验证码输入是否正确
- 协议复选框是否真的被勾选
- 查看 /tmp/after-submit.png 截图

### Q3: 浏览器一闪而过怎么办？
A: 测试结束时浏览器会保持打开60秒，如果提前关闭，可能是出错了，检查终端错误消息。
