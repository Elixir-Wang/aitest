平台提供批量任务处理能力，支持用户一次性上传多个文件或压缩包，由系统自动调用指定智能体逐个处理，并汇总输出结果。

支持批量任务的智能体

目前支持批量任务的智能体需满足以下条件：

绑定对话流，且默认进入对话流的智能体；

对话流中开始节点后的第一个节点是文件上传节点；

智能体需在探索广场发布过（无需等待审核）。

新建批量任务

未进行任何批量任务将展示引导页面，点击立即创建即可开始批量任务。拥有历史批量任务将展示历史批量任务记录，点击右上角新建任务开启新的批量任务。

选择跑批对象

选择跑批对象需完成任务名称填写和智能体选择，具体要求如下：

填写跑批任务名称：输入不超过50字的文本，用于描述该批量任务的目的或内容，便于后续识别；

选择跑批智能体：通过左侧列表的勾选框选择目标智能体，仅支持勾选1个智能体；若需取消选择，可再次点击勾选框，或点击下方“已选择智能体”区域右侧的删除按钮移除。

准备数据集

支持选择数据集上传或本地上传。

数据集上传

新建数据集

点击数据集上传按钮，点击选择框，下方展示可用数据集。

本地上传

点击本地上传，下方展示上传区域，点击【点击上传】按钮，展示选择上传方式弹窗，支持选择上传文件和上传压缩包。

本地上传支持导入常见格式文档和压缩包，上传后的一批数据自动打包成数据集，可在之后的任务中再次复用，您可以进入数据管理对数据集进行编辑。

上传文件

常见文件格式均可兼容。

文档：pdf、docx、txt、html、xlsx、xls、csv

图片：png、jpg、jpeg、webp、tiff、bmp

音频：wav、silk、speex、m4a、ogg- opus、mp3、pcm、aac、amr

可查看上传文件名称、文件大小、上传进度、已上传数据数量，支持删除已上传文件。

下载：下载按钮可下载已上传文件

删除：删除按钮可删除已上传文件

上传压缩包

仅支持上传1个.zip 文件，压缩包内文件数量 ≤ 200，单个文件 ≤ 220MB，总大小 ≤ 2GB。压缩包内文件需为统一类型

可查看已解压文件数量、上传文件名称、文件大小、上传进度、已上传数据数量

下载：下载按钮可下载已上传文件

删除：删除按钮可删除已上传文件。

确认跑批任务

完成配置后，核对任务信息无误，点击确认提交跑批任务。批量任务提交后将自动进入排队流程，耐心等待一会儿可查看任务执行结果。

导出批量任务结果

点击导出按钮，导出批量任务结果。

包含字段如下：

字段	说明
id	执行 ID
task_id	任务 ID
status	执行状态
exec_object_id	执行对象 ID（robot 或 flow ID）
exec_object_type	执行对象类型（robot 或 flow）
exec_start_time	执行开始时间
exec_end_time	执行结束时间
exec_duration	执行耗时（秒）
exec_error	执行错误信息
exec_result	执行 agent 或 flow 输出结果
parse_result	文件解析结果
file_name	文件名称
file_uuid	文件 UUID
create_time	记录创建时间
update_time	记录更新时间
