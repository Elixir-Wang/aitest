本文将以搭建智能面试助手为例，演示如何在百工平台搭建一个自主规划agent。

# 步骤一：创建智能体

1.  如果您需要创建一个自主规划智能体，可按以下步骤进行：
    
2.  登录百融百工平台后，在左侧导航栏中单击创建智能体；
    
3.  选择自主规划Agent，输入智能体名称（必填），可选填智能体头像和智能体描述；
    
4.  选择语种（默认中文，支持英语、法语、日语等多种语言）及嵌入模型，请注意语种和嵌入模型在选择后不能更改；
    
5.  点击弹窗右下角创建，即可完成智能体创建并直接进入基础配置页面。
    

![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202603/2026-03-12_1113080.9765753108109376.png)

# 步骤二：配置智能体

1.  基础模型是智能体的 “大脑”，决定了理解能力、响应速度和推理精度，平台提供多种模型选项，可根据功能复杂度、交互量选择适配需求的基础模型。
    

![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202603/2026-03-12_1113080.6165577254790339.png)

2.  角色设定定义智能体的身份、语气和核心职责，让智能体知道 “自己是谁”“该如何与用户沟通”，避免响应偏离场景。例如智能面试助手的角色设定可以这么描述。
    

![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202603/2026-03-12_1113090.8897567019266414.png)

此外，平台提供了大模型优化功能，方便您只输入简单的要求，就能够输入较完整的提示词。

3.  在其他设置栏，可选择开启长/短期记忆（让智能体自动收集和总结用户提供的对话内容进行存储）、联网搜索能力（大模型会根据用户输入内容自动判断是否联网）和智能追问设置。
    

![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202603/2026-03-12_1113090.3367184010405262.png)

# 步骤三：为智能体添加技能（可选）

技能是智能体的 “具体能力”，如查询数据、统计分析、流程触发等，平台提供技能模板，也支持自定义开发，让智能体适配你的专属需求。在这里，您可以创建并使用“智能面试”知识库，并配置检索规则。

![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202603/2026-03-12_1113090.2650585903306021.png)![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202603/2026-03-12_1113100.0318186837236859.png)

# 步骤四：调试智能体

在配置页面右侧可随时创建对话进行调试，还可查看调试历史。

![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202603/2026-03-12_1113100.10942027100245844.png)

# 步骤五：发布智能体

当您配置好智能体后，即可进行发布操作：

1.  点击页面顶部**发布**按钮，进入发布审核页面；
    
2.  填写发布说明（如版本号、更新内容等）；
    
3.  选择并配置发布平台（默认勾选API调用、网页），确认配置信息无误后点击**发布**提交申请；
    

![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202603/2026-03-12_1113100.3803382248738546.png)
