关于其他开发者公开发布到探索广场的智能体，核心使用流程如下：

1.  找智能体：探索广场找到感兴趣的智能体→点击智能体卡片进入试用页；
    
2.  试智能体：左侧对话交互，右侧查看智能体详情；
    
3.  订智能体（需企业管理员权限）：试用满意→点击右侧**订阅**，智能体复制到企业工坊；
    
4.  用智能体：企业工坊找到已订阅智能体→点击卡片进入对话页。
    

# 在探索广场试用智能体

在探索广场找到您感兴趣的智能体，点击智能体卡片跳转试用页，可在左侧与智能体交互对话，右侧为详情展示区，帮您全面了解智能体信息。

# 订阅 / 取消订阅智能体

*   **订阅**：企业用户订阅智能体需要管理员权限，如果您拥有管理员身份，可直接进入订阅弹窗，填写自定义名称和分组，点击**订阅**按钮完成订阅。订阅Agent相当于**复制**一份备份到企业工坊，备份内容包括Agent配置、插件、对话流；不包括知识库和数据库。
    
*   **取消订阅**：取消订阅需具备**企业管理员权限**（仅管理员可访问智能体管理页）。进入企业智能体管理页后，搜索筛选找到目标订阅类智能体，选择**取消订阅**，可将该智能体从企业工坊移除。取消订阅后，企业内所有用户将无法在企业工坊查看和使用该智能体。
    

![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202603/2026-03-06_1658430.6832141654332065.png)

# 与智能体对话交互

订阅成功后，企业内所有用户（含业务人员、管理员）均可访问企业工坊，浏览、使用企业内可用智能体，点击智能体卡片可直接**使用智能体**。

![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202603/2026-03-06_1658440.5131139341013061.png)

对话页核心功能如下：

*   **新建对话**：如果您希望清空当前对话，可以点击输入框上方**新建对话**按钮，开启新的交互流程；
    
*   **查看与管理历史对话**：点击左上**时钟**按钮弹出历史对话页面，可对历史对话进行置顶、重命名、删除操作。同时可点击批量操作，选择多条历史对话一键删除；
    
*   **长期记忆总结**：对于开启了长期记忆的智能体，点击右上角**大脑**图标可查看，即可查看智能体记录的交互记忆；
    
*   **语音伴读**：百融百工平台提供语音播报能力，智能体的对话回复将自动以语音形式输出，您可以点击页面右上**喇叭**按钮,，实现该功能的开启与关闭；
    
*   **分享**：点击**分享**按钮后，平台提供url链接或二维码，使其他用户可以进入该智能体进行对话交互；
    
*   **收藏**：点击页面右上角**收藏**按钮，收藏后智能体将展示在一级导航栏**收藏栏**，方便您快速进入智能体。
