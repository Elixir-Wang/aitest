# 创建Multi-Agent

如果您需要创建一个Multi-Agent，可按以下步骤进行：

1.  登录百融百工平台后，在左侧导航栏中单击创建智能体；
    
2.  选择Multi-Agent，输入智能体名称（必填），可选填智能体头像和智能体描述；
    
3.  点击弹窗右下角创建，即可完成智能体创建并直接进入基础配置页面。
    

创建好的智能体可以在您的工作空间再次找到，进行使用和配置。

# Multi-Agent基础配置

![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202603/2026-03-06_1611500.7889495691662558.png)

## 欢迎语

欢迎语一栏可为智能体设定第一次打招呼的话术，最多300字。

## 开场热门问题

开场热门话题展示于对话开启时的欢迎语下方，用于引导用户快速发起交互，提升对话启动效率。最多展示5个问题，配置超过5个问题后将随机展示5个问题。

## 短期记忆

开启后，将自动收集和总结用户提供的对话内容进行存储，可在普通对话中通过检索召回的方式使用，也可以在对话流中使用。可在右侧开启并选择短期记忆的对话轮数。

# 添加Agent节点

![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202603/2026-03-06_1611510.3890306946194483.png)

1.  进入Multi-Agent配置页，点击屏幕下方工具栏【添加节点】；
    
2.  拖拽Agent到指定位置，连接边；
    
    1.  连接规则：
        
        *   开始节点只能向外连接一条边；
            
        *   每个智能体支持多条出线连接到其他智能体；
            
        *   每个智能体只允许一条入线连接。
            

![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202603/2026-03-06_1611510.1205668778708533.png)

3.  配置Agent，包括：
    
    1.  **对话模型**：百融百工已接入多款大模型，除了我们的自研大模型Bairong系列之外，也支持部分Qwen、GPT、DeepSeek、doubao等系列模型，可点击基础设置模型栏右侧齿轮按钮进入模型配置弹窗更改对话模型，在这里也可以对发散程度、Top-P以及回复上限进行调整。
        
        ![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202603/2026-03-06_1611520.29911595042366934.png)
        
        *   对话模型种类：包含Bairong、Qwen、GPT、DeepSeek、doubao等多种模型可选择；
            
        *   函数调用：展示该模型是否支持函数调用，不支持函数调用的模型配置的插件并不生效；
            
        *   发散程度：拖动调整模型回复内容是偏严谨还是偏发散；
            
        *   Top-P：调整模型回复内容是偏创造性还是偏集中性，较高的值（接近1）会增加文本的多样性和创造性，而较低的值（接近0）会使文本更加集中和连贯；
            
        *   回复上限：调整该参数可控制大语言模型回复内容的最大长度。
            
    2.  **功能介绍**：描述当前选中Agent的功能，便于理解Multi-Agent流程。例如：用于回答金融知识相关问题，并根据用户需求生成分析建议。
        
    3.  **角色设定**：角色设定是非常重要的配置信息。您可以根据业务需要编写提示词，通过自然语言为智能体设定角色、职能、风格等前置条件，清楚列出机器人的角色、简介、任务与目标、工作流程、技能、限制等，可以提升智能体的回复效果。
        例如：你是一名专业金融分析助手，需要根据用户问题提供准确、简洁的分析结果，并保持正式专业的回复风格。
        
    4.  **资源配置**：目前支持配置插件。
        目前支持：知识库、插件库。配置完成后，智能体可调用对应资源增强回答能力。
        
**知识库配置**

配置知识库能让智能体在对话时检索并使用您配置的知识内容，从而给出更贴合业务的回答。
可以根据实际场景，统一配置所有知识库的全局策略，也可以针对某一个知识库单独优化。

![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202606/2026-06-04_112617_0369850.44252261625358036.png)
**知识库全局设置**
点击知识库标题栏右侧的设置图标，可对该子 Agent 下全部知识库进行统一配置。

**知识库设置**
点击单个知识库条目右侧的设置图标，可对该知识库进行单独配置。

两项设置的配置项与 **自主规划 Agent** 配置方式一致，可直接沿用相同方式操作。

知识库配置通常适用以下场景：
*   企业知识问答
*   文档检索
*   FAQ 场景、
*   内部资料查询
    

**配置插件**

开启插件库开关后，点击右侧「+」按钮即可选择插件。

系统支持：

*   官方插件
    
*   空间插件库
    

插件配置完成后，智能体可调用对应外部能力，例如：

*   网络搜索
    
*   天气查询
    
*   Python 代码执行
    
*   股票信息查询
    

扩展智能体的业务处理能力。


# 发布Multi-Agent

在您完成Agent配置与调试后，若想让其正式投入使用，需要先完成发布操作。目前支持API调用、网页URL集成以及网站嵌入。
