>任务流智能体专为实现自动化处理功能性任务，着重于自动化处理以及批量操作，其流程逻辑相对固定，具备结构化流程化的特点，追求的是高效、稳定的流程执行效果。

# 1. 创建智能体
如果您需要创建一个任务流Agent，可按以下步骤进行：
1. 登录百融百工后，在左侧导航栏中单击创建智能体；
2.  选择任务流Agent，输入必填信息智能体名称，可选填智能体功能介绍和智能体头像；
    1.  模板名称：必填信息，用于描述模板概要，最多50字。
    2. 智能体功能介绍：选填信息，用于对模板详细功能进行介绍，最多300字。
   

![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202604/2026-04-23_135613_0562900.47142622684912017.png)

![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202604/2026-04-23_135510_0367910.2766517688344826.png)
 

3.  选择语种：必填信息，默认简体中文，支持简体中文、繁体中文、英文、法语、印尼语、日语、葡萄牙语、俄语、西班牙语、泰语、阿语、韩语、印地语、德语多种语言。
               
4.  点击弹窗下方创建，即可完成智能体创建，进入配置页面。

# 2. 开始节点和结束节点
系统默认添加开始节点和结束节点，这两个是任务流的特有节点，用于配置任务流输入和输出，不可删除。
## 2.1 开始节点
对于开始节点，该节点支持变量与文件组合输入。变量和文件可设置选择是否为必填项。如未设置必填项，则变量/文件任意有输入即可向后执行。如有必填项，则校验必填项，若输入不包含必填项，则报错。另外，文件上传支持自动断点续传。

![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202604/2026-04-29_113645_7353070.1698892285742487.png)
## 2.2 结束节点
结束节点是任务流的最终节点，用于返回任务流运行后的结果，结束节点后面无法再添加其他节点，所有流程最终都需要连接到结束节点。在该节点支持Json输出与文本输出两种方式。
**Json输出**：Json输出可选择变量管理中的变量，组装多字段输出。

![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202604/2026-04-29_113745_3986700.5322760409434943.png)

**文本输出**：文本输出类似对话流的文本回复节点，可自定义组装变量和文字
# 3. 触发器
任务流agent为单画布模式，左侧列表可配置触发器。任务流agent支持webhook方式的触发器，功能与自主规划agent的webhook触发器一致，触发动作为直接触发当前agent执行；
开启触发器配置，点击“+”创建新的触发器。
![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202604/2026-04-29_154202_7262550.31662276985915516.png)
填写触发器名称，触发事件，支持复制url到你的应用，请求参数用于定义外部调用需要传入的参数，字段匹配可以把外部数据赋值给工作流内部变量。
![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202604/2026-04-29_154059_9094230.7151920306612973.png)

触发器创建完成后，可对已存在的指定触发器进行查看、编辑、删除操作。
![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202604/2026-04-29_154429_6197100.9304535119939034.png)

  # 4. Agent配置

## 4.1 信息加工
任务流的信息加工模块支持「大模型变量赋值」、「普通变量赋值」、「知识检索变量赋值」、「文件检索变量赋值」、「文件解析」。其中，除了「大模型变量赋值」节点，其他节点的配置方式同对话流一致。

**大模型变量赋值**
与对话流相比，任务流的大模型变量赋值节点不支持短期记忆、长期记忆和节点输出配置，其他配置与对话流一致。

![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202604/2026-04-29_140338_7820309.896395766118005e-05.png)
## 4.2 分支
### 4.2.1 条件判断

「条件判断」是使用条件判断语句，对前文对话中收集到的**变量**信息按照条件逻辑进行分类，不同的类型可流转至不同的流程分支。

![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202604/2026-04-29_135507_1749960.5748012201000718.png)

### 4.2.2 语义判断

「语义判断」节点可以用语义相关度做用户回复的语义分类，使用起来更灵活。与对话流不同的是，任务流的语义判断节点仅支持「根据变量判断」
![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202604/2026-04-29_134747_5097140.20064020170468544.png)

**高级配置：** 支持进行召回与Rerank设置。

![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202604/2026-04-29_134922_6593470.31608782906400423.png)

### 并行分支
任务流支持在画布中连线配置并行分支，支持一个节点同时连线，多个节点实现并行，支持分支后嵌套分支。

![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202604/2026-04-29_155229_3848260.20049906179094745.png)
## 4.3 触发动作
支持API调用和代码执行两种方式，配置方式同对话流。

## 4.4 资源
支持插件、数据库，配置方式同对话流。


 # 5. 文件、变量管理（同对话流）
 任务流的变量和文件配置与对话流一致。与对话流不同的是，任务流不支持「实体」的管理和配置。

# 8. 发布

# 9. 发布管理
在首页「发布管理」页面，可以查看已发布的agent的调用历史与数据分析，并且可以对已发布的agent执行更新发布平台、下线操作。

![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202604/2026-04-29_153833_6668170.8274180584820755.png)
## 9.1 调用历史
调用历史包括调试、使用、接口调用的调用记录，支持查看调用记录和对应的日志；

![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202604/2026-04-29_153606_9949730.015391554679996533.png)
## 9.2  数据分析

统计智能体任务的调用情况与运行表现，了解任务执行效率、调用规模及 Token 消耗情况，便于进行运营分析与效果评估。
可通过时间范围筛选查看不同周期内的数据变化趋势，包括近 3 天、近 7 天、近 30 天及累计数据。

![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202604/2026-04-29_153629_0206560.9914267539122749.png)

## 9.3 更多
### 9.3.1 更新发布平台

当智能体已发布后，可通过“更新发布平台”功能调整当前可用的发布渠道。 
1. 进入「发布管理」页面。
2. 在智能体列表中找到需要更新的平台。
3. 点击右侧「···」操作按钮。
4. 选择「更新发布平台」。

![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202604/2026-04-29_153543_7988210.23748947564356615.png)

5. 在弹窗中勾选或取消需要发布的平台。
6. 点击右上角「确认更新」完成配置。


![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202604/2026-04-29_153732_5800630.9848236317735516.png)
更新成功后，系统将按照最新配置同步智能体发布平台。

### 9.3.2 下线

如需停止当前已发布的智能体服务，可在发布管理中执行下线操作。

![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202605/2026-05-19_103155_1626090.37829932865816096.png)
![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202604/2026-04-29_153753_9604420.4175506114394981.png)

1. 进入「发布管理」页面。
2. 在智能体列表中找到需要下线的智能体。
3. 点击右侧「···」操作按钮。
4. 选择「下线」。

下线成功后，智能体状态将更新为“已下线”，对应发布平台将停止访问与调用。
