# 欢迎来到百融百工👏

百融百工是一个AI智能体创作平台，它基于大型语言模型技术，让使用者以零代码或低代码的方式，快速构建出智能体。我们的目标是通过这个简洁而强大的工具，助力企业和个人轻松实现大模型技术的实用化。我们的愿景是创造一个既用户友好又操作简便的产品，让每一位用户都能迅速且轻松地开发出满足特定需求的智能体。

*   智能体：一种能够感知环境并做出自主决策以完成特定任务的软件系统。结合了人工智能（AI）技术，包括自然语言处理（NLP）、机器学习（ML）和自动化流程，能够与用户交互并执行各种复杂任务。简单来讲，智能体即一个能够理解用户意图、依据用户指令、帮助用户完成各种需求的智能机器人。
    

# 百融百工的优势是什么💎

## 1.  应用场景广泛
    

生成的智能体既可以是企业的数字员工、智能客服，为企业节约人力成本；又可以是提升个人效率的专属工具，提升个人工作效率，减少枯燥重复类工作。

## 2.  操作便捷
    

不需要代码知识，非技术人员也可以轻松上手。

不需要复杂的prompt能力，即可完成角色个性、知识经验、能力范围等基础设定。

通过上传文件或复制粘贴等方式，即可实现智能体专属知识的训练，创建一个智能体最快只需要2分钟。

## 3.  技术算法专业
    

平台拥有强大的算法技术支撑，链接自主开发的大语言模型、多个开闭源模型，并自研关键业务算法，提升智能体对海量文档的快速学习/查找能力，精准识别复杂场景的问题意图。

## 4.  数据隐私和风控安全
    

平台构建了完善的数据安全体系，通过领先的技术和严格的风控措施，既能保护用户信息以及数据的安全性，又能针对敏感类问题进行判断和阻断。
