插件模块支持关联空间插件库及官方插件资源，为智能体拓展多样化功能（如数据查询、业务办理、第三方服务调用等），适配复杂业务场景需求。通过灵活配置插件参数与调用规则，可让智能体精准匹配实际使用场景，提升交互效率与功能覆盖度。

# 添加插件

绑定插件时，支持从空间插件库和官方插件中进行选择，单个智能体最多支持绑定20个工具。

![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202603/2026-03-02_1429400.09410530451929644.png)

![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202604/2026-04-23_164329_5341510.5330172475186102.png)

**添加插件后，可点击该插件对应的设置按钮：**
* 修改工具描述，使其更符合自己使用工具的场景，提升插件召回的准确率。
* 定义参数值传递方式，提升插件提参的准确率。
![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202604/2026-04-23_164125_1991910.016797853616174807.png)
* 定义输出模式，支持直接回复插件原始结果，或模型基于角色设定与插件返回结果总结后回复。

![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202604/2026-04-23_163725_1444140.9127535365910899.png)

# 插件绑定后配置
此外，为确保大模型在适当时机调用插件，需要在基础设置的**角色设定**中明确希望大模型**何时调用插件**。

![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202603/2026-03-02_1429410.9683342796207659.png)

在配置界面右侧，您可直接进行**插件调用测试**。在输入框内进行能触发插件调用的问题，可以检查大模型是否有调用目标插件的行为，智能体回复中将直接展示实际工具调用结果。

# 删除插件

如果您不需要某个插件了，可点击该工具右侧减号按钮删除。

![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202603/2026-03-02_1429410.704149255248314.png)

# 插件接入网络要求

为保证插件顺利调用，使用时需注意网络连接情况。

* 互联网插件：需要保证互联网可访问
 
* 内网插件：插件服务端需要添加百工域名、ip为白名单，并联系赛博坦研发后台配置参数和确认网络策略；
