## 一、什么是线上观测？

**线上观测**是一套面向Agent 的具备自动化质量监控与评估能力的功能。

当 Agent 发布上线后，系统会从真实用户交互中持续采样 Trace 数据，结合预先配置的评估器，对 Agent 的输出效果进行周期性评估，并通过图表、报表与明细数据的形式呈现运行质量。

通过线上观测，你可以：

* 在 **真实生产数据** 中持续发现 badcase
 
* 用 **量化指标** 判断 Agent 版本优化是否有效
 
* 将高价值线上数据沉淀为 **评测数据集**，用于后续调优
 
* 减少人工抽样与排查成本，实现自动化运维
 

## 二、适用场景

线上观测适用于以下典型场景：

* **上线质量监控**：监控生产 Agent 是否出现异常输出或质量波动
 
* **版本效果对比**：对比不同时间段、不同版本的效果变化趋势
 
* **持续评估机制**：周期性评估 Agent 的稳定性与长期表现
 
* **数据沉淀**：将真实 Trace 转化为评测数据，支撑后续效果评测与自动优化
 

## 三、功能总览

线上观测主要包含以下能力模块：

* **观测任务**：配置采样规则与评估器，自动执行线上评估
 
* **评估器**：定义评估规则（Prompt + 模型），用于自动打分
 
* **任务详情与数据分析**：查看趋势图表、子任务结果与明细数据
 
* **数据导出**：导出 CSV，用于人工分析或外部系统处理
 

## 四、如何使用线上观测

### 4.1 创建观测任务（核心入口）

进入路径：

> 空间 → **线上观测** → 新建任务

![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202603/2026-03-06_1701500.48653472490334926.png)

创建观测任务分为 **两步**：

### 第一步：配置任务信息与采样策略

1️⃣ 基础信息

* **任务名称（必填）**：用于区分不同观测任务
 
* **描述（可选）**：补充说明该任务的目标或背景
 

![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202603/2026-03-06_1701510.22931813863364725.png)

2️⃣ 观测对象

* 选择需要监控的 **已发布自主规划智能体**
 
* 仅可选择当前空间内、你具备管理权限的 Agent
 

![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202603/2026-03-06_1701510.9444378374287373.png)

3️⃣ 采样策略

* **采样比例**：从线上 Trace 中随机抽取的比例（1%–100%）
 
* **采样数据总上限**：限制任务整体最多评估的数据量
 

> 系统会先按比例采样，再按上限截断，确保性能与成本可控。

4️⃣ 时间范围与执行频率

* 设置采样 Trace 的 **时间区间**
 
* 支持：
 
 * 不重复（一次性观测）
 
 * 按天重复
 
 * 按周重复
 

通过周期性执行，可实现 **持续线上监控**。

完成后，点击「下一步」。

### 第二步：配置评估器

在该步骤中，为观测任务指定用于打分的评估器。

* 可选择 **1–5 个评估器**
 
* 每个评估器需指定具体版本
 
* 同一任务中不能重复选择同一个评估器
 

你可以：

* 直接选择已有评估器
 

![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202603/2026-03-06_1701510.492786823000647.png)

* 在下拉框中快速跳转新建评估器
 

![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202603/2026-03-06_1701520.5111451450060359.png)

配置完成后，点击「完成」，系统将创建观测任务并等待资源分配完成后开始执行。

## 五、观测任务列表说明

创建成功后，你可以在 **观测任务列表** 中查看所有任务。

列表中展示的信息包括：

* 任务名称 / 观测对象
 
* 当前状态（进行中、已暂停、已完成、队列中等）
 
* 任务进度（总条数 / 成功 / 失败）
 
* 时间范围、创建人、创建时间
 

![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202603/2026-03-06_1701530.034103498685437605.png)

![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202603/2026-03-06_1701530.3600632961084713.png)

支持操作：

* 暂停 / 继续
 
* 查看详情
 
* 取消或删除任务
 

![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202603/2026-03-06_1701530.2561388116032445.png)

 

> 已完成或已取消的任务仅支持查看与删除，不可再次执行。

## 六、观测任务详情解读

进入任务详情页后，你可以从 **宏观趋势 → 子任务 → 明细数据** 三个层级理解 Agent 表现。

### 6.1 总览图表

* 每个评估器对应一张图表
 
* 默认展示各子任务的 **平均得分变化趋势**
 

![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202603/2026-03-06_1701540.9852966422513991.png)

* 支持：
 
 * 折线图 / 柱状图切换
 
 
 ![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202603/2026-03-06_1701550.32888785702232726.png)
 
 * 全屏查看
 
 
 ![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202603/2026-03-06_1701550.7900611187186445.png)
 
 * 多评估器对比
 

这些图表可用于判断：

* Agent 效果是否随时间波动
 
* 新数据或新版本是否带来提升或退化
 

### 6.2 子任务列表

子任务代表一次具体执行周期（如某一天、某一周）。

你可以查看：

* 每个子任务的执行状态
 
* 各评估器的平均得分
 
* 子任务生成时间与完成时间
 

![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202603/2026-03-06_1701560.856535093481838.png)

支持：

* 搜索与筛选
 
* 导出单个子任务的执行结果（CSV）
 

### 6.3 子任务数据明细

进入子任务后，可查看每一条 Trace 的评估结果：

* 用户输入
 
* Agent 输出
 
* 各评估器打分
 
* 执行状态（成功 / 失败）
 

![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202603/2026-03-06_1701560.10664416724123649.png)

你可以：

* 快速定位低分或失败样本
 
* 点击查看单条 Trace 的调用链详情
 
* 导出全部明细数据，用于人工复盘或训练数据构建
