# 支持自动优化的智能体

* 智能体类型为自主规划智能体
 
* 智能体有正式发布版本
 
* 最新的正式发布的版本中智能体不能开启以下配置
 
 * 长期记忆
 
 * 联网搜索
 
 * 对话流
 
 * 插件
 
 * 数据库
 

# 新建自动优化任务

1. 选择目标智能体：点击**新建自动优化**，在可选智能体列表中选择目标智能体（智能体需满足以上条件）；
 

![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202603/2026-03-06_1702280.2658933764257392.png)![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202603/2026-03-06_1702300.4085058846121963.png)

另外，从智能体编辑页面也可以进入自动优化菜单；

![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202603/2026-03-06_1702310.5440714031169894.png)

2. 选择优化数据：从线上观测任务数据中，筛选并勾选需要优化的单条数据（线上观测任务开始时间需在智能体创建之后）；
 

![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202603/2026-03-06_1702320.9196303016042754.png)

3. 选择评估数据：选择评测集作为评估数据，用于验证优化后智能体的响应质量，若列表为空，可在效果评测-评测集-新建评测集；
 

![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202603/2026-03-06_1702330.08158190834399937.png)

4. 优化策略设置：根据智能体实际问答表现，选择以下1种或组合使用2种优化策略，精准提升智能体响应能力；
 

* 优化提示词：基于实际问答中的错误案例（bad case），调整提示词内容，明确回答逻辑、格式或约束条件，提升智能体对同类问题的理解与泛化能力；
 
* 新增QA对：针对提示词难以覆盖的复杂或特殊场景，直接提供高质量的问题与标准答案示例，补充至知识库，确保关键问题准确响应；
 

![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202603/2026-03-06_1702350.5102459387902285.png)

5. 点击开始自动优化提交任务，立即进入队列排队执行。
 

# 查看自动优化结果

入口：智能体编辑页面【自动优化】-【查看优化列表】或一级菜单【自动优化】

![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202603/2026-03-06_1702360.7554039707361604.png)![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202603/2026-03-06_1702360.7726329957275873.png)

功能描述：

* 通过该功能查看智能体的优化任务列表（该页面与自动优化任务页面相同）
 
* 通过详情查看优化详细信息
 
* 通过自动优化报告查看优化结果，并决定是否应用当前优化版本
 

任务页展示了当前智能体的所有自动优化任务，其中任务名称后缀包含日期和任务序号，如20260121144033\_0001（yyyyMMddHHmmss\_版本序号）。

详情页状态栏展示任务所处状态，依次为：

* 排队中：任务已提交，正在排队
 
* 执行中：任务正在执行
 
* 失败：任务执行失败
 
* 已完成：任务执行完成
 

数据条数分为优化数据和评估数据，用户可以分别查看优化后智能体在两种数据集上的表现得分情况（若有提升则会显示向上的提升标识，同理显示下降、不变标识）。

任务列表支持搜索功能，可通过任务名称、任务状态进行筛选和搜索。

![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202603/2026-03-06_1702370.8599088269117677.png)

## 自动优化任务详情页

入口：自动优化任务列表-任务【详情】

功能描述：通过【详情】按钮查看单个优化任务的信息，展示优化任务的智能体名称、类型、prompt、实际消耗token数、优化策略、数据概览。

* 实际消耗token数需要优化任务处于“已完成”状态，若未完成则会显示“计算中”。
 
* 数据概览默认展示优化数据页，点击可切换展示评估数据。

## 提交当前版本

入口：自动优化任务列表 - 任务【详情】- 点击【提交当前版本】，显示提交弹窗

![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202603/2026-03-06_1702400.12705676753059514.png)![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202603/2026-03-06_1702400.07440990285627713.png)

* 优化策略：
 
 * 优化策略默认全部勾选
 
 * “优化提示词”不可取消勾选
 
 * 点击优化策略选项右侧的高亮“详情”在弹窗展示详情
 
 * 知识库：
 
 * 点击详情可查看具体问题、答案
 
 * 选择QA导入的知识库：
 
 * 点击新增QA右侧的【选择导入目录】，显示选择知识库列表（当前Agent绑定的知识库）页面
 
 
 ![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202603/2026-03-06_1702410.9110080675433502.png)![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202603/2026-03-06_1702410.7539583189648966.png)
 
 
 
 * 选择知识库后，展示“选择目录”页面，选择目录后
 
 * 点击【导入这里】，选择当前目录，返回提交版本页面，将“待选择”文字改为目录名称，【代选择】功能不变
 
 * 点击【上一步】，回到选择知识库列表页
 
 
 
 
* 点击【提交】，校验通过后，跳转版本发布页面。如果用户选择QA导入知识库而没有对知识库的编辑权限，会提示“没有{知识库}编辑权限，发布失败”。
