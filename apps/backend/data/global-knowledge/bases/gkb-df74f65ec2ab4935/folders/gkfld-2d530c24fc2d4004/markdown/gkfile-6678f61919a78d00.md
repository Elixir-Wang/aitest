# 1. 企业微信机器人集成

将百工平台已配置并发布的智能体，接入企业微信，在企业微信内以机器人形式向成员提供对话服务。

完成集成后，**绑定的企业微信账号**将作为**该智能体的机器人账号**使用，无法作为其他用途。
该机器人对应在百工平台绑定、配置并发布的智能体。
## 1.1 创建智能体&能力配置
与 **钉钉集成** 中，智能体创建、能力配置方式相同。
## 1.2 配置企业微信集成

步骤一：进入企业微信配置入口

* 选择目标智能体，进入【更新发布平台】页面。
 
* 在发布渠道列表中找到 企业微信 一行，点击该行右侧 【配置】 按钮。
 

![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202606/2026-06-04_1432200.2639317969112417.png)

系统将弹出 「配置企业微信」 窗口，并提示该功能的开通或变更需要您咨询我们的产品顾问。

请按照以下顺序操作：

1. 联系产品顾问或客服，完成企业微信集成的开通确认（首次开通、更换企微账号、解绑等场景均需沟通）。
 
2. 沟通完成后，勾选【已和客服沟通完毕，可以进行下一步配置】并点击【下一步】。
 

![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202606/2026-06-04_1432200.46362361290470244.png)
步骤二：配置参数：
在 「配置企业微信」 配置页中，填写以下必填项后点击【确定】完成绑定。
![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202606/2026-06-04_1432210.3814109477583918.png)

* 企业微信认证的公司名称：与客服沟通后，经过认证后的企业名称；
 
 定位:

 **手机端**: 企业微信→我→公司信息→所在企业；
 
 **PC端**: 左上角个人信息→头像下方企业名称。
 
 ![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202606/2026-06-04_1432200.5130417301366339.png)
 
* 企业微信账号名称：企业微信账号的用户名
 

![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202606/2026-06-04_1432210.12411144277505104.png)


## 1.3 发布至企业微信

完成以上配置后，确认发布智能体。

系统会自动完成：

* 智能体发布
* 企业微信账号与当前智能体绑定
* 企业微信平台同步配置

发布成功后，当前账号将作为机器人，在企业微信中使用。
## 1.4 在企业微信中使用机器人
打开企业微信客户端后，可通过搜索机器人名称找到已发布的智能体机器人，便可与其正常对话。

![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202606/2026-06-05_173812_3776410.8439083766457867.png)
## 1.5 注意事项

* 企业微信账号完成绑定后，将作为当前空间的专属企业微信接入账号使用，同一企业微信账号暂不支持在多个平台或空间重复登录绑定。
* 如需更换绑定账号，请先联系产品顾问解除当前绑定关系后再重新配置。
* 请确保所绑定的企业微信账号符合企业微信官方平台规范。因账号异常、权限变更或违反企业微信相关规则导致的功能受限、**账号封禁**等情况，可能影响企业微信相关功能的正常使用。
* 企业微信绑定完成后，建议不要随意修改**企业名称**、**企业简称**、**用于绑定的企业微信账号名**等企业信息。信息变更后可能导致账号识别异常、配置失效或需要重新进行绑定。
* 建议使用企业统一管理的企业微信账号进行配置，避免因个人账号变更、离职或权限调整导致服务中断。
