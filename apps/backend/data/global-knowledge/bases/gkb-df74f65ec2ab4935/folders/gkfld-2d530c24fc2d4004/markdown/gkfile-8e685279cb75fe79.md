# 1. 钉钉机器人集成
支持将平台内创建的智能体发布至钉钉平台，发布完成后，可在钉钉中通过机器人形式进行对话使用。
用户可通过配置钉钉应用信息，实现智能体与企业钉钉机器人的集成部署，适用于企业内部问答、业务助手、流程协同、知识问答等场景。
## 1.1 创建智能体
进入工作台后，点击创建智能体，完成基础信息配置。

![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202605/2026-05-25_110838_6798130.6724632538744387.png)
填写或选择内容：
* 智能体名称
* 智能体头像
* 功能介绍
* 默认语种
* 模型配置

![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202605/2026-05-25_110924_4777570.15968092680189427.png)
其中：
* 智能体名称将作为后续钉钉机器人名称展示；
* 功能介绍用于描述智能体的核心能力与应用场景；
* 模型配置用于定义智能体默认使用的大模型能力。

配置完成后，可进入智能体编辑页面继续完善能力配置。
## 1.2 配置智能体能力
进入智能体编辑页面后，可根据业务需求配置智能体能力。
* 提示词用于定义智能体角色、回复风格及业务规则；
* 欢迎语用于用户首次进入会话时的默认展示内容；
* 资源配置中，知识库与插件能力可增强智能体的数据检索与业务处理能力。

![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202605/2026-05-25_111800_1384790.05490129718247272.png)
配置完成后，可通过右侧调试窗口验证回复效果。

## 1.3 配置钉钉集成
在发布窗口下方的【发布平台】区域中，选择【钉钉】并点击右侧【配置】按钮。


![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202605/2026-05-25_172444_5863880.8621985144034048.png)
随后填写以下信息：

* Client ID
* Client Secret

![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202605/2026-05-25_112044_1444940.23494120334337865.png)
* Client ID：钉钉应用凭证（原 AppKey 和 SuiteKey）
* Client Secret：钉钉应用凭证 (原 AppSecret 和 SuiteSecret)
* 群聊上下文配置：多人在群内\\@智能体提问时，是按1对1记录对话历史还是按1对多记录对话历史。可选择单人对话或者多人对话。
* 是否选择钉钉消息模板：选择“是”则使用有“赞/踩”选项的消息模版，选择“否”则为钉钉原始消息格式。

上述信息需通过企业内部钉钉应用申请获取。
通常由企业管理员或相关负责人在钉钉开放平台创建应用后，通过内部流程申请对应凭证。
配置完成后，保存当前钉钉集成信息。
## 1.4 发布至钉钉平台
完成钉钉配置后，确认发布智能体。

系统会自动完成：
* 智能体发布
* 钉钉机器人绑定
* 钉钉平台同步配置

发布成功后，当前智能体即可在钉钉中使用。

## 1.5 在钉钉中使用机器人
打开钉钉客户端后，可通过搜索机器人名称找到已发布的智能体机器人。

![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202605/2026-05-25_113000_7791380.3098844839511746.png)
进入机器人会话页面后，即可与智能体进行对话交互。

![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202605/2026-05-25_115057_4927620.663586409922879.png)
机器人将基于当前已发布版本的配置内容提供对应能力，包括：
* 智能问答
* 知识检索
* 内容生成
* 业务处理等能力


## 1.6 注意事项

* 发布前需确保智能体已完成基础配置；
* Client ID 与 Client Secret 需与当前企业钉钉应用保持一致；
* 若修改智能体配置内容，需重新发布后方可同步至钉钉端；
* 若钉钉端未同步最新内容，可检查当前发布版本是否成功更新。

# 2. 钉钉开放平台配置
## 2.1 机器人配置
点击上方蓝色字体可进入钉钉后台创建钉钉应用。

1. 机器人设置及添加权限
 

* 进入钉钉开放平台【机器人】菜单，打开灰置开关，垂直滚动菜单至 【消息接收模式】设置其为 HTTP模式 （此处默认为Stream模式，需手动下拉切换至HTTP模式）;
 
* 填写消息回调地址（企业内部自己的URL）。
 

![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202604/2026-04-27_1805130.1805818774065776.png)

![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202604/2026-04-27_1805130.4539019213417651.png)

## 2.2 钉钉后台创建钉钉应用

1. 钉钉机器人创建
 
 进入【钉钉开发者后台】，登录后点击【创建应用】，填写应用名称、描述。
 
 ![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202604/2026-04-27_1805130.13141912168278347.png)
 
 ![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202604/2026-04-27_1805130.007635732883712221.png)
 
 创建后在【凭证与基础信息】处可查看、复制应用的【Client ID】&【Client Secret】（用于Cybotstar钉钉配置的填写）。
 
 ![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202604/2026-04-27_1805140.012065491700930298.png)
 
2. 应用能力添加
 

点击【添加应用能力】，选择 "机器人" ，点击【添加】，填写机器人基本信息。

![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202604/2026-04-27_1805140.44667272052646356.png)
