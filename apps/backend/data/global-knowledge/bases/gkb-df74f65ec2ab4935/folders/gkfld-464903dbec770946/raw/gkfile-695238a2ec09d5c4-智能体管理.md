# 查看智能体使用情况

## 对话历史

支持整通会话查询和单条日志查询，记录智能体与用户的交互过程，快速定位问题、优化智能体。

### 整通会话查询

完整还原用户与智能体的交互过程。

![](https://www.cybotstar.cn/agent-document-content/media/1/202603/2026-03-06_1657330.019939224514628373.png)

点击智能体回复下方按钮可以查看**详细日志**和**回复来源**。

![](https://www.cybotstar.cn/agent-document-content/media/1/202603/2026-03-06_1657340.1370487696687258.png)

### 单条日志查询

提供日志的多维度筛选与查询功能，支持精准定位单条日志。

![](https://www.cybotstar.cn/agent-document-content/media/1/202603/2026-03-06_1657350.5523099723741405.png)

点击单条日志，可跳转详细日志页。展示会话处理的完整日志信息，包括基础信息、调用树、时间轴、节点详情、输入内容展示以及输出结果展示。

![](https://www.cybotstar.cn/agent-document-content/media/1/202603/2026-03-06_1657360.307682895019176.png)

## 数据分析

进入数据分析页面可查看智能体运营数据，支持数据统计、趋势分析与用户洞察。

### 数据统计

数据统计页提供智能体核心运营数据概述。

![](https://www.cybotstar.cn/agent-document-content/media/1/202603/2026-03-06_1657360.14964304649871873.png)

* 时间筛选：自定义区间或快捷选择（最近3/7/30天）；
 
* 核心指标：Token消耗量、用户数、对话数；
 
* 趋势分析：展示访问趋势和响应耗时。
 

### 用户洞察

用户洞察页提供多维度数据助力了解用户行为。

![](https://www.cybotstar.cn/agent-document-content/media/1/202603/2026-03-06_1657370.831385131122016.png)

* 关键用户指标：展示DAU、MAU、30日用户留存率等关键用户指标；
 
* 用户高频词汇：展示筛选日期范围内，包含关键词的对话数及涉及关键词的用户数；
 
* 日活跃用户数趋势：横轴为日期，纵轴为日活用户数；
 
* 人均交互次数趋势：横轴为日期，纵轴为每日人均交互次数。
 

# 版本管理

## 更新发布平台

当智能体处于**生效中**状态时，可通过以下步骤调整发布渠道：

1. 在版本列表中找到目标智能体，点击**更新发布平台**；
 
2. 页面将以列表形式展示所有可配置的发布平台，每个平台包含名称、功能说明、配置入口；
 
3. 已发布的平台默认勾选，可通过多选框勾选 / 取消勾选百工探索广场以及百工企业工坊，外部渠道不支持取消勾选；
 
4. 确认选择后，点击右上角**确认更新**，系统将保存配置并跳转回发布管理页。
 

## 下线

点击**下线**将使智能体从**所有平台**移除，状态变更为“已下线”，并在项目开发页同步更新为“草稿”。

## 一键回滚

当需要恢复历史版本时，可通过以下步骤操作：

1. 在版本列表中找到需要回滚的**回退版本**或**历史迭代**版本，点击**一键回滚**；
 
2. 系统将弹出确认弹窗：**回滚将覆盖当前生效版本，是否继续？**；
 
3. 点击**确认**后，该版本将变为**生效中**，原生效版本将转为**回退版本**，并显示**回退至 xxxx 版本（版本号）**的标识。
 

# 长期记忆

发布管理页支持配置智能体的长期记忆功能，空间长期记忆模拟大脑的长期记忆，通过LLM能力，提取用户表述中的关键内容进行存储、向量化。这一功能旨在提升机器人与用户的交互能力和应用价值。尤其在持续服务、个性化体验和复杂任务处理方面具有明显优势。
