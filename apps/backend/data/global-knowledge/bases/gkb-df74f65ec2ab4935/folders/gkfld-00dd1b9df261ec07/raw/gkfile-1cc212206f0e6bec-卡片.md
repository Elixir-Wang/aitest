卡片用于将智能体输出以结构化、可视化和可交互的形式展示。用户可以在资源库中统一创建和维护卡片，通过可视化编辑器组合布局、文本、图片、按钮、表单和图表等组件，再将已发布的卡片绑定到对话流或插件输出。

卡片与智能体配置相互独立。同一张卡片可以被多个智能体复用；卡片修改后，需要重新发布版本，并在绑定位置手动升级后才会生效。

# 1. 卡片管理

## 1.1 进入卡片资源库

进入路径：

1. 登录百融百工。
2. 在左侧导航栏中选择【创作中心】→【资源库】。
3. 选择【空间资源库】。
4. 在资源类型中选择【卡片】。

卡片列表展示卡片名称、描述、发布状态、创建人、引用智能体数量和操作入口。支持通过关键词搜索卡片，并可在卡片视图和列表视图之间切换。

![卡片资源库](https://www.cybotstar.cn/agent-document-content/media/1/202606/2026-06-10_162711_1498470.2262823956755422.png)

卡片状态包括：

- **草稿**：卡片尚未发布，不能作为正式版本绑定使用。
- **已发布**：卡片至少存在一个已发布版本，可以在对话流或插件中绑定。

## 1.2 新建卡片

新建卡片的操作步骤如下：

1. 在卡片资源库右上角点击【添加资源】。
2. 在新建卡片弹窗中填写卡片名称和卡片描述。
3. 点击【确定】，系统创建卡片并进入卡片编辑器。

![新建卡片](https://www.cybotstar.cn/agent-document-content/media/1/202606/2026-06-10_162712_8105530.42412616515969903.png)

字段说明：

- **卡片名称**：必填，最多 30 个字符，用于识别和搜索卡片。
- **卡片描述**：选填，最多 300 个字符，用于说明卡片的用途、展示内容和适用场景。

建议使用能够体现业务用途的名称，例如“天气查询卡片”“订单状态卡片”“客户信息卡片”。

## 1.3 卡片列表操作

点击卡片或操作菜单，可以执行以下操作：

- **编辑**：进入卡片编辑器，修改当前草稿。
- **复制**：复制卡片名称、描述和草稿内容，并进入副本编辑页。
- **导出**：将卡片配置导出为 JSON 文件。
- **删除**：删除未被引用的卡片。
- **批量删除**：进入批量操作模式，选择多张卡片后统一删除。
- **导入**：上传符合卡片导出格式的 JSON 文件并创建新卡片。

已发布且正在被智能体引用的卡片，不允许直接删除，需要先解除全部绑定。编辑这类卡片时，系统会提示当前引用对象；编辑不会立即影响已绑定智能体。

# 2. 卡片编辑器

卡片编辑器采用左、中、右三栏结构：

- 左侧为组件、变量、大纲和模板。
- 中间为卡片画布。
- 右侧为当前选中组件的属性配置。

顶部工具栏用于返回资源库、修改卡片信息、查看保存状态、预览、保存模板、发布和查看历史版本。

![卡片编辑器](https://www.cybotstar.cn/agent-document-content/media/1/202606/2026-06-10_162714_6778970.10885425702701679.png)

## 2.1 自动保存

编辑器会自动保存卡片草稿，顶部显示当前保存状态：

- **保存中**：正在将编辑内容保存为草稿。
- **已保存**：当前画布内容已成功保存。
- **保存失败**：本次保存未成功，需要检查网络后再次操作。

自动保存只更新草稿，不会自动生成新的发布版本，也不会影响已经绑定到智能体的版本。

## 2.2 编辑卡片基本信息

点击顶部卡片名称右侧的编辑图标，可修改：

- 卡片名称。
- 卡片描述。

名称和描述用于资源库管理，不直接决定卡片在对话中的展示内容。

# 3. 组件与布局

可以点击组件，或将组件拖动到画布中的目标位置。布局组件可以继续承载其他组件，用于组织卡片结构。

## 3.1 布局组件

当前支持以下布局：

- **单列布局**：内容纵向排列，适合标题、正文、图片等基础结构。
- **多列布局 1:1:1**：将内容分为三个等宽区域。
- **列表布局**：按纵向列表组织多个内容项。
- **网格布局**：按网格排列重复内容。
- **横滑布局**：内容横向排列，可用于横向浏览多个项目。
- **浮动布局**：用于需要叠加或自由定位的内容。

布局组件可配置列间距、行间距、内边距、圆角、背景、点击动作和显示条件。部分布局支持固定内容和变量循环两种模式。

## 3.2 基础组件

当前支持以下基础组件：

- **标题**：展示卡片主标题或分区标题。
- **文本**：展示说明、摘要和变量内容。
- **按钮**：触发发送消息、打开链接或禁用卡片等动作。
- **图片**：展示固定图片或变量图片。
- **图标**：展示图形化标识。
- **标签**：展示状态、分类或短文本。
- **评分**：展示评分结果。
- **分割线**：分隔不同内容区域。
- **音频**：展示并播放音频内容。
- **视频**：展示并播放视频内容。

标题、文本、按钮等组件支持插入卡片变量，使同一张卡片能够根据智能体运行结果展示不同内容。

## 3.3 表单组件

当前支持：

- **按钮选择**：提供一个或多个选项，由用户点击选择。
- **动态表单**：配置输入字段并收集用户填写的内容。

表单交互产生的卡片动作会返回到对话运行链路，由智能体继续处理。

## 3.4 图表与自定义组件

当前支持：

- **ECharts 图表**：通过图表配置展示柱状图、折线图、饼图等数据可视化内容。
- **信息图**：使用信息图模板组织数据和说明。
- **自定义 HTML**：编写完整 HTML，并可包含 CSS 和 JavaScript。

自定义 HTML 适合内置组件无法覆盖的展示需求。使用时需注意代码安全、终端兼容性和卡片尺寸，避免引入无法在目标页面正常运行的外部依赖。

## 3.5 属性配置

选中画布中的组件后，可在右侧修改对应属性。不同组件的配置项不同，常见配置包括：

- 内容、字号、颜色、对齐方式和间距。
- 图片地址、填充方式和对齐位置。
- 布局列数、行列间距和内边距。
- 背景颜色、背景图片和透明度。
- 按钮文案、动作类型、链接或发送消息内容。
- 图表配置、表单字段和选项。
- 图层顺序和显示条件。

# 4. 变量

卡片变量用于接收智能体运行过程中产生的数据。同一张卡片绑定到不同智能体或不同节点时，可以通过变量映射展示不同数据。

![创建卡片变量](https://www.cybotstar.cn/agent-document-content/media/1/202606/2026-06-10_162716_1924850.5022712634100669.png)

创建成功后，变量会显示在左侧变量列表中。

![卡片变量列表](https://www.cybotstar.cn/agent-document-content/media/1/202606/2026-06-10_162717_8295870.7685113844604278.png)

## 4.1 创建变量

在编辑器左侧选择【变量】，点击【添加】后配置：

- **变量名称**：必填，最多 64 个字符。
- **变量类型**：必填。
- **默认值**：必填，用于编辑和预览时展示效果。

变量名称必须以英文字母或下划线开头，只能包含英文字母、数字和下划线；同一卡片内变量名称不可重复。

## 4.2 变量类型

当前支持以下类型：

- **String**：字符串，例如城市名称、状态说明。
- **Number**：数字，例如温度、金额、数量。
- **Boolean**：布尔值，取值为 `true` 或 `false`。
- **Array**：数组，默认值必须为合法 JSON 数组。
- **Object**：对象，默认值必须为合法 JSON 对象。

Array 和 Object 使用 JSON 编辑器填写默认值。若 JSON 格式错误，或填写内容与变量类型不一致，系统不允许保存。

## 4.3 在组件中引用变量

创建变量后，可在支持变量的组件内容中插入变量。例如：

- 标题组件引用 `city`，展示查询城市。
- 文本组件引用 `temperature`，展示实时温度。
- 列表布局引用 `forecast`，循环展示未来天气。
- 图片组件引用图片 URL 字段。

对于 Array 类型变量，可配置循环项和最大展示长度。运行时系统按绑定的上游数组生成对应数量的内容项。

## 4.4 条件显示

组件和布局可以设置显示条件。条件由以下内容组成：

- 左值：选择一个卡片变量或变量内部字段。
- 运算符：根据变量类型选择可用的比较方式。
- 右值类型：选择常量或另一个变量。
- 右值：填写常量，或选择用于比较的变量。

常见场景：

- 当数据列表不为空时显示列表区域。
- 当状态等于“成功”时显示成功标签。
- 当数值大于指定阈值时显示提示信息。
- 当布尔变量为 `true` 时显示操作按钮。

# 5. 大纲与模板

## 5.1 大纲

大纲按组件层级展示卡片结构，可用于：

- 查看布局和组件的父子关系。
- 快速定位并选中组件。
- 调整组件顺序。
- 识别复杂卡片中的嵌套结构。

## 5.2 使用模板

模板分为：

- **我创建的**：当前空间用户保存的卡片模板。
- **官方模板**：平台提供的通用卡片模板。

应用模板会替换当前画布内容，操作前需要确认。建议在应用模板前确认当前草稿已经自动保存。

## 5.3 保存为模板

画布中存在内容时，可以点击顶部【保存模板】，填写模板名称和模板描述。保存后的模板可在其他卡片中复用。

模板名称最多 30 个字符，模板描述最多 300 个字符。

# 6. 预览与发布

## 6.1 预览卡片

点击顶部【预览】，可以查看卡片的实际展示效果，并在 PC 和移动端预览模式之间切换。

预览会使用变量默认值渲染卡片，适合检查：

- 内容是否完整。
- 布局是否拥挤或错位。
- 文本是否溢出。
- 图片、音频、视频和图表是否正常。
- 按钮、选择项和表单交互是否符合预期。
- 条件显示是否正确。

![PC 端卡片预览](https://www.cybotstar.cn/agent-document-content/media/1/202606/2026-06-10_162719_3252740.10584589853966209.png)

切换至【移动端】后，可以检查窄屏下的内容排列和交互效果。

![移动端卡片预览](https://www.cybotstar.cn/agent-document-content/media/1/202606/2026-06-10_162720_9656530.26450804536334105.png)

## 6.2 发布卡片

卡片配置完成后，可在编辑器顶部或预览弹窗中点击【发布】。

发布时填写：

- **版本号**：选填，最长 64 个字符。系统会获取建议的下一版本号；留空时可由后端自动生成。
- **发布描述**：选填，最多 500 个字符，用于记录本次版本的修改内容。

![卡片发布配置](https://www.cybotstar.cn/agent-document-content/media/1/202606/2026-06-10_162722_6289220.4241442020409468.png)

若版本号使用三段数字格式，每段范围为：

- 主版本号：0 至 99。
- 次版本号：0 至 9。
- 修订号：0 至 9。

示例：`1.0.0`、`1.1.0`。

发布时系统会生成卡片缩略图。发布成功后，卡片可以在对话流或插件中绑定。

# 7. 历史版本

点击顶部历史版本图标，可查看当前草稿和所有已发布版本。

![卡片历史版本](https://www.cybotstar.cn/agent-document-content/media/1/202606/2026-06-10_162724_4688090.6301259708908221.png)

版本列表展示：

- 版本号。
- 是否为最新版本。
- 发布时间。
- 发布人。
- 版本预览。

选择历史版本后，可以点击【恢复此版本】。恢复操作会用该版本内容覆盖当前配置，并将内容作为当前草稿载入；该操作不会删除已有发布版本。

若卡片已被智能体引用，恢复时系统会提示相关引用对象。恢复后仍需重新发布，并在绑定位置升级版本，才会影响智能体运行效果。

# 8. 绑定卡片

已发布卡片可以绑定到对话流卡片回复节点，也可以作为插件输出卡片。

## 8.1 选择卡片

绑定页面左侧支持：

- 搜索卡片。
- 在【我创建的】和【官方卡片】之间切换。
- 查看卡片名称、版本、发布时间和缩略图。
- 识别是否存在待更新版本。

只能将已发布版本用于正式绑定。

## 8.2 变量绑定

选择卡片后，将卡片变量与当前节点或插件的上游输出变量进行映射。

变量映射需满足：

- 卡片变量路径必须存在。
- 上游变量路径必须合法。
- 标量变量不能绑定循环数组路径。
- Array 类型变量需选择上游数组。
- 数组循环可设置最大长度。
- 同一循环变量在不同字段中的数组路径和范围必须保持一致。

例如：

| 卡片变量 | 类型 | 上游变量 |
|---|---|---|
| `city` | String | `location.city` |
| `temperature` | Number | `weather.temp` |
| `forecast` | Array | `weather.forecast` |

## 8.3 发送方式

对话流绑定支持以下卡片会话方式：

- **新增一条卡片消息**：将卡片作为一条新的对话消息发送。
- **覆盖已有卡片**：当卡片模板和变量绑定一致时，更新已经发送的卡片内容。
- **节点推送消息**：由节点主动推送卡片消息。

覆盖模式适合订单状态、任务进度等需要持续更新的场景；新增模式适合每次结果都需要独立保留的场景。

## 8.4 对话流绑定

在对话流中添加卡片回复节点后：

1. 打开卡片配置。
2. 点击绑定卡片。
3. 选择已发布卡片。
4. 配置变量映射。
5. 选择发送方式。
6. 点击【确定】完成绑定。

绑定后可在节点配置中编辑或解绑卡片。解绑操作需要二次确认。

## 8.5 插件绑定

插件可以配置卡片作为输出形式。操作流程与对话流绑定一致，通过统一的绑定页面选择卡片、映射变量并确认。

插件场景还可以配置是否保留插件总结输出，使对话中同时展示文本总结和卡片。

# 9. 版本升级与引用限制

卡片发布新版本后，已经绑定旧版本的节点或插件不会自动升级。

绑定页面会显示【待更新】提示，可查看最新版本预览并选择：

- **暂不升级**：继续使用当前绑定版本。
- **立即升级**：将绑定版本更新为最新版本。

版本和引用规则如下：

- 编辑已发布卡片不会直接影响线上运行。
- 需要先发布新版本，再手动升级绑定。
- 被引用的卡片不能直接删除。
- 删除前需要解除所有智能体、节点或插件绑定。
- 复制卡片会创建独立副本，副本与原卡片的版本和绑定互不影响。

# 10. 运行效果

智能体运行到卡片回复节点或插件卡片输出时，系统执行以下流程：

1. 根据卡片 ID 和已绑定版本读取卡片结构。
2. 获取当前节点或插件的上游输出数据。
3. 按变量映射将实际值写入卡片变量。
4. 由前端卡片渲染器递归渲染布局和组件。
5. 用户点击按钮、提交表单或选择选项后，将卡片动作返回到对话链路。

卡片支持以下消息形态：

- 单独发送卡片。
- 文本与卡片组合发送。
- 更新已经发送的卡片。
- 回传卡片交互动作。

卡片最终展示效果受对话终端能力影响。发布前应在目标终端检查卡片宽度、媒体加载、图表、表单和按钮交互。

# 11. 使用建议

- 卡片名称应体现业务用途，不建议使用“测试1”“新卡片”等无明确含义的名称。
- 先定义变量，再设计组件，便于统一数据结构。
- 对列表数据设置合理的最大展示长度，避免卡片过长。
- 同一张卡片尽量承担单一业务目标。
- 发布描述应记录本次修改内容，便于版本回溯。
- 发布后先在测试对话中验证，再升级正式绑定版本。
- 自定义 HTML 应谨慎使用，优先使用平台内置组件。
