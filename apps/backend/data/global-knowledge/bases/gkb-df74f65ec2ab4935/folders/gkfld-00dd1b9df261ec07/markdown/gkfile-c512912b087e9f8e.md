# 1. 插件管理
 

## 1.1 插件的定位

在用户与机器人的对话过程中让机器人拥有实时数据查询的能力。空间资源库可创建私人专属插件，公开资源库可查看官方插件。

## 1.2 插件创建顺序


![](https://www.cybotstar.cn/agent-document-content/media/1/202605/2026-05-13_174752_8149540.2566896815267574.png)

在「资源库-插件库」中新建插件（支持 API 插件、MCP 插件和IDE插件三种类型）。

> 插件在空间资源库下共用，官方插件在公开资源库中直接可用。

## 1.3 插件参数配置

### 1.3.1 api插件

插件基础信息页：

![](https://www.cybotstar.cn/agent-document-content/media/1/202603/2026-03-06_1655360.201543888967315.png)

![](https://www.cybotstar.cn/agent-document-content/media/1/202603/2026-03-06_1655360.11279742481000521.png)

> * 基础信息配置：插件头像、插件名称、插件简介、插件调用方式
> * 支持配置插件的统一url，各个工具的url拼接插件url和工具的名称；
> * 支持配置header，可以支持鉴权信息放在header中，支持bearer等常见的方式；
> * 支持配置插件的超时时间，默认为60s；
> * 点击确认后直接进入“工具列表页”；
 

工具列表页：

![](https://www.cybotstar.cn/agent-document-content/media/1/202603/2026-03-06_1655370.18919719385186795.png)

编辑工具页：

![](https://www.cybotstar.cn/agent-document-content/media/1/202603/2026-03-06_1655370.48787543251422727.png)

>* 页面左上角插件名称点击编辑，进入“插件基础信息页”； 
> * 工具列表展示信息见原型，支持工具的新增、编辑、调试、删除、启用禁用； 
> * 调试状态取最后一次通过插件管理页面请求工具时的状态，包括调试、获取输出参数，如未请求过工具，则为未知；
> * 点击创建工具按钮进入创建工具弹窗；
> * 工具名称，英文，支持字母、下划线；
> * 工具路径，填写子路径，完整路径拼接插件url和路径；
> * 工具方法即调用方法，支持post、get等四种方法；
> * 手工维护输入参数后，输出参数支持通过自动解析功能一键获取；
> * 禁用的参数在通过agent或工作流插件节点调用时隐藏；


> **api插件手动编辑，agent调用逻辑：**
> * 如工具无agent绑定，则支持编辑，关闭的工具绑定时不可见；
> * 如工具有agent绑定，则提示工具有agent绑定，不允许禁用、编辑输入参数，如果删除，自动解绑；
 

### 1.3.2 mcp插件

![](https://www.cybotstar.cn/agent-document-content/media/1/202603/2026-03-06_1655380.07095143996302444.png)

> * 支持选择mcp插件类型：SSEConnection | StreamableHttpConnection ，WebsocketConnection和StdioConnection暂不支持； 
> * 其他插件基础信息配置同api插件； 
> * 点击确定后，进入工具列表页，直接请求mcp服务器，获取工具信息；
 

列表和编辑页

![](https://www.cybotstar.cn/agent-document-content/media/1/202603/2026-03-06_1655380.8877615280661256.png)![](https://www.cybotstar.cn/agent-document-content/media/1/202603/2026-03-06_1655390.5279760202160094.png)

> * 页面左上角插件名称点击编辑，进入“插件基础信息页”；
> * 工具列表页支持工具的更新（从服务器重新获取）、查看、启用禁用；
> * 更新工具成功后更新时间变更；
> * 点击编辑可以查看工具的具体信息，包括工具名称、工具描述、输入参数信息，并维护输出参数信息；
> * 输出参数信息需请求工具获取并自动解析； 
> * 输出参数支持维护参数描述，支持启用禁用，禁用的参数在通过agent或工作流插件节点调用时隐藏；
> **mcp插件更新，agent调用逻辑：**
> * 如工具找不到，则agent自动解绑该工具；
> * 如工具能找到，自动更新插件、工具的相关信息，输入参数如无原配置信息，则默认大模型提取方式； 
> * 工具有绑定agent时不允许禁用；
 

==注：
插件接入网络要求：
互联网插件：需要保证互联网可访问；
内网插件：插件服务端需要添加百工域名、ip为白名单，并联系赛博坦研发后台配置参数和确认网络策略；==


### 1.3.3 ide插件

插件基础信息页：

![](https://www.cybotstar.cn/agent-document-content/media/1/202605/2026-05-13_145201_9408390.8866774603134543.png)

> * 基础信息配置：插件头像、插件名称、插件简介、运行类型、超过时间；
> * 支持选择 IDE 插件运行类型：`Python` | `JavaScript`；
> * 支持配置插件的超时时间，默认为60s；
> * 点击确认后直接进入“工具列表页”；

工具列表页：


![](https://www.cybotstar.cn/agent-document-content/media/1/202605/2026-05-13_160356_2813420.44912506092872584.png)

>* 页面左上角插件名称点击编辑，进入“插件基础信息页”； 
> * 工具列表展示信息见原型，支持工具的新增、编辑、调试、删除、启用禁用； 
> * 更新工具成功后更新时间变更；
> * 点击创建工具按钮进入创建工具弹窗； 创建工具弹窗支持选择沙箱、填写工具名称和描述；

编辑工具页：


![](https://www.cybotstar.cn/agent-document-content/media/1/202605/2026-05-13_152242_7240540.9465694607835133.png)


![](https://www.cybotstar.cn/agent-document-content/media/1/202605/2026-05-13_152312_7617770.15677663849373735.png)


![](https://www.cybotstar.cn/agent-document-content/media/1/202605/2026-05-13_162933_6518300.31929306191454865.png)
> * 点击编辑可以查看工具的具体信息，工具编辑页支持元数据和代码两个Tab；
> * 元数据 Tab 用于定义工具契约，包括入口函数、输入参数、输出参数；
> * 入口函数，填写代码中实际执行的函数名称，默认为 main，需与代码页中的函数名保持一致；
> * 输入参数，点击「添加参数」手工维护，支持配置参数名、参数类型、参数说明、是否必填、操作；
> * 输出参数，点击「添加参数」手工维护，支持配置参数名、参数类型、参数说明、操作；
> * 代码 Tab 支持代码编辑和保存，保存后代码同步至平台托管运行环境；
> * 右侧测试验证区域根据输入参数自动生成测试输入表单，支持填写参数后点击「运行测试」显示运行结果；
> * 工具编辑后发布前需运行测试成功，测试通过后才允许发布；
> **ide插件手动编辑，agent调用逻辑：**
> * 如工具无agent绑定，则支持编辑、禁用、删除；
> * 如工具有agent绑定，则提示工具有agent绑定，不允许禁用、编辑输入参数或删除；
> * 如插件内有工具绑定agent，则不允许删除插件，需先解绑所有工具；


## 1.4 官方插件问答效果
**添加官方插件操作步骤**


1. 进入应用编辑页面
进入智能体应用编辑页后，点击顶部导航栏中的「资源配置」。
2. 打开插件配置
在「资源配置」页面中，找到「插件」模块，点击右侧的「+」按钮。
![](https://www.cybotstar.cn/agent-document-content/media/1/202605/2026-05-19_112617_7164410.30958989524258296.png)

3. 进入官方插件列表
系统会弹出插件选择窗口，点击顶部的「官方插件」标签页。
4. 选择需要添加的插件
在官方插件列表中： 可通过搜索框输入插件名称快速查找插件，也可直接浏览插件列表选择需要的插件。 找到目标插件后，点击右侧「添加全部」按钮。
![](https://www.cybotstar.cn/agent-document-content/media/1/202605/2026-05-19_112644_0961810.1884260573358486.png)
5. 完成插件添加
添加成功后，插件会显示在「插件」列表中，表示已成功绑定到当前应用。
6. 配置角色提示词
返回「基础配置」页面，在「角色设定」中补充插件调用说明。
例如： 当用户咨询天气相关问题时，调用已配置的天气查询插件进行回答。 用于引导模型正确调用插件能力。

### 1.4.1「国内天气」官方插件

* 参考问法：查询XX（地）X天的天气情况
 
* 问答效果：对话框内实时报告查询地白天/夜间天气/温度，底端生成天气文字总结。
 

![](https://www.cybotstar.cn/agent-document-content/media/1/202603/2026-03-06_1655390.1365681314387419.png)

### 1.4.2 「股票实时价格」官方插件

* 参考问法：查询一下XX（公司）今天的/实时股价
 
* 问答效果：对话框内以表格形式展示股票代码/名字、今日开盘价、昨日收盘价、今日最高/低价、当前价格、竞买/卖价、成交/股票数、52周最高/低价、日期、时间，底端生成文字总结。
 

![](https://www.cybotstar.cn/agent-document-content/media/1/202603/2026-03-06_1655390.7125924228247165.png)
