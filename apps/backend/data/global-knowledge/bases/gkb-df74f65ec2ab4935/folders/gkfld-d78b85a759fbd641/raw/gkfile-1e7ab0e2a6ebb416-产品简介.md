# 产品概述

**百融百工**是由百融云创推出的一站式大模型智能体（Agent）平台，致力于为个人开发者与企业用户提供高效、安全、灵活的智能体构建、部署与管理能力。平台支持百融自研大模型、主流商业大模型及第三方开源大模型，通过“LLM + 记忆 + 规划技能 + 工具使用”的智能体架构，赋能用户快速打造面向多样化业务场景的专属智能体。

无论您是希望快速验证想法的独立开发者，还是寻求规模化部署智能应用的企业团队，百融百工都能提供从开发、测试、发布到监控的全生命周期支持。

**Agent = LLM+ 记忆 + 规划技能 + 工具使用**

# 产品定位

百融百工定位于**企业级与开发者友好的大模型智能体平台**，核心价值包括：

## 1. 应用场景广泛
 

生成的智能体既可以是企业的数字员工、智能客服，为企业节约人力成本；又可以是提升个人效率的专属工具，提升个人工作效率，减少枯燥重复类工作。

## 2. 操作便捷
 

不需要代码知识，非技术人员也可以轻松上手。不需要复杂的prompt能力，即可完成角色个性、知识经验、能力范围等基础设定。通过上传文件或复制粘贴等方式，即可实现智能体专属知识的训练，创建一个智能体最快只需要2分钟。

## 3. 技术算法专业
 

平台拥有强大的算法技术支撑，链接自主开发的大语言模型、多个开闭源模型，并自研关键业务算法，提升智能体对海量文档的快速学习/查找能力，精准识别复杂场景的问题意图。

## 4. 数据隐私和风控安全
 

平台构建了完善的数据安全体系，通过领先的技术和严格的风控措施，既能保护用户信息以及数据的安全性，又能针对敏感类问题进行判断和阻断。

# 适用人群

## 1. 个人开发者
 

平台提供SDK、可视化编排工具以及完善的插件体系，使用者可快速开发具备记忆、推理、工具调用能力的智能体，轻松实现独立开发项目、场景化智能体原型验证、轻量化智能应用快速落地等。

## 2. 企业用户
 

实现组织内 Agent 项目、模型资源、成员权限的统一管理，支持定制化发布策略与全流程使用监控，在保障数据安全合规的前提下，最大化提升资源利用率与团队协作效率，助力企业级智能应用规模化部署、跨部门智能体协同管理、行业专属智能体定制与落地等。

# 核心功能

## 1. 智能体[开发与发布](gkfile-695238a2ec09d5c4)
 

百融百工提供面向个人开发者与企业用户的低代码/无代码智能体开发环境。通过直观的可视化操作界面、丰富的模块化组件（如记忆模块、工具调用插件、知识库接入等）以及覆盖客服、营销、办公、金融等多场景的配置模板，用户可快速完成智能体的角色设定、对话逻辑、知识支撑和功能扩展。平台支持一键发布至Web、企业微信、钉钉、API 接口等多种渠道，实现高效部署与无缝集成，全面满足个性化与规模化应用需求。

## 2. 智能体[效果评测](gkfile-6e8b8a9b038985a9)
 

为确保智能体在实际业务中的可靠性与有效性，百融百工内置专业的效果评测体系。支持从回答的准确性、完整性、相关性、实用性等多个维度进行量化评估，并提供大模型自动评测与人工打分双模式。用户可基于评测结果快速定位问题、迭代优化提示词或知识库，持续提升智能体性能与用户体验。

## 3. 智能体[使用](gkfile-1b24deb18eb4ad8c)与[批量任务](gkfile-ea5f7c46e5c3f67d)
 

在百融百工平台，用户不仅能够自主开发智能体，还能通过探索广场搜索筛选优质智能体，订阅到工作空间即可复用。平台汇聚了覆盖客服、营销、HR、金融、教育等多个领域的精选智能体模板，支持按行业、功能、评分等维度筛选。

另外，百融百工不仅支持单次交互式对话，还提供强大的批量任务处理能力。用户可上传数据集，配置任务模板，由智能体自动执行大规模、重复性的文本生成、信息提取、内容审核、客户回访等操作。

## 4. 企业智能体[监控](gkfile-e39f6a147fcc4913)与[管理](gkfile-dcc492d2f9d9ae55)
 

针对企业级用户，百融百工推出“企业工坊”模块，实现智能体资产的集中化管理与协同运营。企业可统一管理成员权限、共享知识库与模型资源，并实时查看智能体的核心运营指标，包括调用量、活跃用户、业务分布、满意度等。平台支持智能体全生命周期管理，涵盖版本控制、对话历史回溯、性能分析、安全审计等功能，为企业提供数据驱动的决策依据，助力智能体高效运维与持续优化。
