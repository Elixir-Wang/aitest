# 1. 转人工如何配置
 

可在[高级配置](gkfile-e767d507fdc18ac4)中查看转人工的具体配置方法，包括转人工条件、转人工参数、转人工方式，以及API调用解包示例，我们也提供了转人工意图识别与情绪识别的提示词建议，方便您按需配置。

# 2. 智能体如何集成到钉钉或企微等外部渠道
 

需通过工单申请获取专属配置信息，申请路径：钉钉工作台-【工单系统】-【IT】-选择【钉钉需求申请单】或相应其他服务，填写申请详情点击【提交】。

# 3. 数据库上传数据显示“部分成功”，该如何排查？
 

可点击状态右侧**下载**按钮，导出未成功的数据明细进行排查。常见问题为字段超限问题，可尝试把超限制列的字段类型改为**长文本**后重新上传。

# 4. 自研插件是否需要自行部署服务器
 

是的，需要发布成http服务。

# 5. 上传文件的大小限制
 

**对话流节点上传文件大小限制**

| 文件类型 | 上传（文件大小上限） | 解析（自研文档解析服务，文件大小上限） | 页数限制 | 对应格式 |
|----------|----------------------|------------------------------------------------------------|------------|-----------------------------------------------|
| 音频 | 100M | 音频解析（自研、腾讯）服务最大文件大小都是 100M | - | wav、mp3、pcm、silk、m4a、aac、amr |
| PPT | 50M | 100M | 1000页 | ppt、pptx |
| PDF | 20M | 100M | 1000页 | pdf |
| DOC | 20M | 20M | 无 | docx、doc |
| 图片 | 20M | 100M | 无 | png、jpg、jpeg、webp、tiff、bmp、heic |
| EXCEL | 20M | 20M | 无 | xls、xlsx |
| 其他 | 20M | 20M | 无 | html、txt、csv、md |


**知识库上传文件大小限制**

| 文件类型 | 上传（文件大小上限） | 解析（自研文档解析服务，文件大小上限） | 页数限制 | 对应格式 |

| PPT | 50M | 100M | 1000页 | ppt、pptx |

| 其他 | 20M | 20M | 无 | html、txt、csv、md、xml |


# 6. 智能体是否支持主动推送等触发类任务
 

可查看[高级配置](gkfile-e767d507fdc18ac4)中触发器相关描述，配置定时触发、系统事件触发或Webhook触发，使智能体主动发起会话。

# 7. 在使用批量任务、自动优化等功能时找不到对应智能体是什么原因？
 

目前平台对于能实现以上功能的智能体有一定限制，如果发现找不到

| 功能 | 对智能体的要求 |
|--------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 批量任务 | 1. 绑定对话流，且默认进入对话流的智能体；
2. 对话流中开始节点后的第一个节点是文件上传节点；
3. 智能体需在探索广场发布过（无需等待审核）。 |
| 自动优化 | 1. 智能体类型为自主规划智能体
2. 智能体有正式发布版本
3. 最新的正式发布的版本中智能体不能开启以下配置：
 • 长期记忆
 • 联网搜索
 • 对话流
 • 插件
 • 数据库 |
