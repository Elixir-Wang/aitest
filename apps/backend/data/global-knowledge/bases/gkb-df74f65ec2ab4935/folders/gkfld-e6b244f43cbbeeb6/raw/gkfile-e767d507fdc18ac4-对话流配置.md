# 定位

在一些真实的业务场景下，机器人不仅需要提供基本的知识问答能力，同时它需要理解复杂的业务需求，具备任务的识别、引导、完成能力，并提供连贯的交互体验。例如，当用户需要需要查询订单状态时，需要机器人：

1. **识别意图**：机器人需要准确识别用户的需求意图。
 
2. **引导对话**：通过一系列对话引导用户提供必要信息，如订单号和下单时间。
 
3. **完成任务**：它会使用从用户中收集来的信息帮助用户查询到订单状态。
 

这个过程可能需要几轮对话来确保信息的完整性和准确性。机器人会在对话的过程中引导用户进入一个封闭的会话流程，确保用户咨询的对话交互都是围绕这个明确的目标进行的，这个封闭的对话流程就是「对话流」。

进入「对话流」的时机，是用户的提问命中了对话流绑定的意图。退出「对话流」的时机，是对话流内节点流转至末端节点时，即可退出。

目前对话流已全面升级为用户当前自主规划Agent的专属资产，创建自主规划Agent，点击[高级配置]，[点击编辑]对话流进入对话流编排页面。

## 2.实体管理、变量、文件管理

### 2.1 实体管理

「实体管理」弹窗可以进行实体信息新建、编辑、删除等操作。实体信息可在「收集实体信息填槽」节点中进行收集。

**实体**：

* 在对话系统中，实体通常指对话内容中的**具体信息点**，如人名、地点、组织、日期、时间等。
 
* 实体是对话中识别出来的数据片段，它们是对话内容的一部分，用于理解用户的意图和提供准确的响应。
 
* 实体可以选择系统预定义的，也可以进行新建自定义实体。
 

![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202603/2026-03-06_1654290.5184096439702272.png)

### 2.2 变量管理

「变量管理」弹窗可进行变量信息的新建、编辑、删除等操作。

变量信息会随着执行过程的变化而变化，如{last\_user\_response}变量，是指上一次用户回复的内容，因此会随着对话交互而变化。

**变量**：

* 编程中，变量是存储数据值的容器，它们可以是不同类型的数据，如数字、字符串、对象等。
 
* 变量在程序执行过程中可以被赋值和修改，它们用于存储和操作数据。
 
* 变量有名称（标识符），这个名字在程序的上下文中是唯一的，用于引用变量存储的数据。
 


![](https://saibotan-pre.100credit.cn/agent-document-content/media/1/202604/2026-04-23_120845_3965500.5355746372067514.png)

## 3.对话节点

### 3.1 大模型回复

==「大模型回复」节点，为大模型生成机器人回复用户内容的节点。==可在右侧的配置栏中进行相关信息的配置。

* 数据来源：a.仅大模型回复（仅通过大模型获取答案不进行知识检索）；b.大模型+知识库回复（需要进行知识检索后再由大模型生成回复，需要多填写“知识库提问”字段，以便获取准确的知识检索内容）
 
* 节点通过要求：开启后，可填写通过该节点的具体要求，当对话内容满足「节点通过要求」时才会进入下一个节点，如未满足时则仍在该节点继续对话。
 
* 下拉选：a.仅prompt（传给大模型的内容不包含上下文）；b.prompt+上下文（传给大模型的内容包含本次对话前10轮对话的内容）
 
* prompt输入框：此处是填写给大模型生成内容的提示信息的。可用&引用变量、用@引用实体。
 
* 大模型配置：模型选择（选择不同模型）、函数调用（默认支持）、发散程度（模型回复是严谨还是发散）、top-P（核采样参数，用于控制AI生成文本多样性，P值越低，输出越确定；P值越高，多样性越强）、回复上限（最大值为16000）、角色设定（可单独编写回复机器人的人设信息）

### 3.9 长期记忆赋值

#### 3.9.1 长期记忆概述

长期记忆用于在多轮对话中持续保存用户相关信息，使智能体在不同对话间能够保持上下文一致性与个性化理解。

在对话流层面，开发者可通过配置节点实现长期记忆的写入与读取，用于跨节点、跨会话的数据留存与调用。

长期记忆在对话流中主要有以下三种操作方式：

1. **记忆写入**：将变量或文本内容写入长期记忆；
 
2. **记忆读取**：从长期记忆中取出已存储的变量、画像或记忆点；
 
3. **记忆检索召回**：通过向量语义检索（RAG）召回与当前问题相关的历史记忆内容。
 

通过这些配置，开发者可让对话流实现：

* 跨节点持久化变量（替代数据库反复读写）；
 
* 多轮上下文回忆；
 
* 个性化问答、推荐、续接任务等高级交互体验。
 

对话流「长期记忆赋值」配置时，需与所选择的「自主规划智能体」相互配合配置，配置路径为 「创建智能体」 - 「自主规划智能体」 - 「基础配置」 - 「长期记忆」，具体可查看[对话流配置](gkfile-e767d507fdc18ac4)。

若选择「全部记忆」

**智能体范围：**

## 3.20 对话流节点复制

对话流内支持多节点复制粘贴，提升流程搭建复用与编排效率。（注意：跨空间或跨环境复制或导入后，无权限的配置将清空，请重新检查节点配置）
当前支持以下两种场景的多节点复制操作：
* 1.同一画布内复制粘贴：用户在同一个对话流画布中，选中一个或多个节点，复制后粘贴，快速生成配置相同的节点。
 
* 2.跨画布复制粘贴：用户可以在对话流A中复制选中的节点，然后打开对话流B，将节点粘贴到B的画布中，实现配置的跨流程复用。
 
* 用户可通过以下方式选中需要复制的单/多个节点：
1、按住CTRL/command，逐个点击。
2、从画布的某个点开始，点击鼠标左键 拉出一个矩形框。
* 复制内容包括节点、节点的配置、节点之间的连线 。粘贴完成之后，全节点处于选中状态，可整体位移。

大模型token数：本轮对话的所有大模型相关节点的总token数（各节点相加）；

## 5、多人协作
当前低代码平台的工作流画布支持多人在线协作编辑，且采用实时自动保存机制：用户对画布的任何改动（节点增删、拖拽、配置修改等）都会立即自动保存。
当两个用户同时编辑同一画布：后保存的用户收到版本冲突提示“已有用户更新草稿配置，当前操作未生效，请主动刷新获取最新草稿后重新编辑“。用户手动刷新页面后，能拉取到最新画布内容进行编辑。
