# 测试场景

根据用户故事创建完整测试场景，包含测试目标、起始条件、用户角色、分步测试操作和预期结果。

**适用场景：** 编写 QA 测试用例、创建测试计划、定义验收测试场景，或验证用户故事实现。

**参数：**
- `$PRODUCT`：产品或系统名称
- `$USER_STORY`：要测试的用户故事（标题和验收标准）
- `$CONTEXT`：补充测试背景或约束

## 分步流程

1. **评审用户故事** 和验收标准
2. **定义测试目标** - 要验证的具体行为
3. **建立起始条件** - 系统状态、数据准备、配置
4. **识别用户角色** - 谁执行测试操作
5. **创建测试步骤** - 将交互拆成逐步操作
6. **定义预期结果** - 每一步之后可观察的结果
7. **考虑边界场景** - 无效输入、边界条件
8. **输出详细测试场景** - 可直接供 QA 执行

## 测试场景示例

**测试场景：** 在商品页查看最近浏览商品

**测试目标：** 验证“最近浏览”区域正确展示，并排除当前商品。

**起始条件：**
- 用户已登录，或浏览器历史记录已启用
- 用户在当前会话中至少浏览过 2 个商品
- 用户当前位于一个不同于之前浏览商品的商品页

**用户角色：** 在线购物用户

**测试步骤：**
1. 进入任意商品页 → 页面底部应展示包含已浏览商品的区域
2. 滚动到页面底部 → “最近浏览”区域可见，并展示商品卡片
3. 验证商品缩略图 → 图片、标题和价格展示正确
4. 检查当前商品 → 当前商品不在最近浏览列表中
5. 点击某个商品卡片 → 用户跳转到对应商品详情页

**预期结果：**
- 最近浏览区域仅在至少浏览过 1 个历史商品后出现
- 区域展示 4-8 个信息完整的商品卡片
- 当前商品从列表中排除
- 每张卡片展示“X 分钟/小时前浏览”的时间戳
- 点击卡片会跳转到正确商品页
- 性能：该区域在 2 秒内加载完成
