# 百融统⼀登录认证授权中⼼产品需求说明 

# 书 

## 1. 项⽬概述 

### 1.1 项⽬背景 

#### 新版百融官⽹升级后，将承担百系产品统⼀⼊⼝职能。官⽹不仅作为品牌展示与产品导航⼊⼝，同时 

#### 需逐步承接百系产品统⼀注册、统⼀登录、统⼀认证与统⼀身份识别能⼒。 

#### 当前百系产品存在独⽴登录⼊⼝、独⽴账号体系、独⽴认证⽅式，⽤户从官⽹进⼊不同产品时存在重 

#### 复登录、身份割裂、状态不统⼀等问题，官⽹⽆法形成统⼀⽤户承接链路。 

#### 因此需建设统⼀登录认证授权中⼼，作为官⽹统⼀身份基础设施，对内输出标准化认证能⼒，对外形 

#### 成统⼀登录⼊⼝。 

### 1.2 项⽬⽬标 

#### 建设统⼀登录认证授权中⼼，实现：统⼀注册、统⼀登录、统⼀认证、统⼀授权、统⼀身份标识、单 

#### 点登录（SSO）、单点登出（SLO）、官⽹统⼀⼊⼝能⼒。 

## 2. 产品定位 

### 2.1 核⼼职责 

#### 统⼀登录认证授权中⼼负责：⽤户注册、⽤户登录、统⼀登录认证授权、统⼀ UID 管理、票据签发、 

UserInfo 服务、SSO、SLO、登录审计。 

### 2.2 职责边界 

#### 统⼀认证中⼼负责身份层统⼀，不替代各产品业务系统。 

各产品继续负责：本地账号、本地 Session、租户、⻆⾊、菜单、数据权限、业务权限。 

## 3. 建设原则 


### 3.1 统⼀认证，产品⾃治 

#### 统⼀登录认证授权中⼼负责统⼀身份识别与认证授权，各产品保留⾃身账号体系及权限体系。 

### 3.2 渐进式推进 

#### 允许各产品保留现有登录⽅式作为过渡⼊⼝，但统⼀认证中⼼逐步成为官⽹主登录链路。 

## 4. ⽤户模型 

### 4.1 C端⽤户 

#### 个⼈⽤户统⼀注册与登录。 

### 4.2 B端⽤户 

#### 企业管理员、企业成员。 

### 4.3 B+C混合身份⽤户 

#### ⽀持同⼀⽤户在统⼀身份下承载多身份场景。 

## 5. 总体架构 

#### 官⽹统⼀⼊⼝ → 统⼀登录认证授权中⼼ →百系产品 → 本地账号映射 + 产品权限体系 

## 6. 核⼼机制设计 

### 6.1 Unified UID 

所有⽤户在统⼀认证中⼼内拥有唯⼀身份标识（Unified UID）。 

### 6.2 本地账号映射 

统⼀认证中⼼不直接替代各产品本地账号体系，各产品通过 Unified UID 与本地账号建⽴映射关系。 

映射关系：Unified UID ↔ Local User ID 


### 6.3 ⾸次绑定机制 

#### ⽤户⾸次通过官⽹进⼊产品时：已存在本地账号则绑定本地账号；不存在本地账号则创建本地账号； 

#### 存在冲突则进⼊冲突处理流程。 

## 7. 核⼼业务流程 

### 7.1 官⽹登录 

#### ⽤户在官⽹完成统⼀注册或登录后，建⽴统⼀身份状态。 

### 7.2 官⽹进⼊产品 

官⽹ → 统⼀认证中⼼ → 产品侧 → 本地 Session 

⽬标：官⽹登录后进⼊产品免⼆次登录。 

### 7.3 产品直接访问 

#### 产品 → 统⼀认证中⼼ → 登录 → 回跳产品 

## 8. 登录体验要求 

#### ⽤户登录⼀次后，可访问已接⼊产品；官⽹进⼊产品⽆需重复登录；登录状态统⼀；⾸次绑定标准 

#### 化；登录异常可控。 

## 9. 登出机制 

### 9.1 本地登出 

#### 仅退出当前产品，不影响官⽹及其他产品登录状态。 

### 9.2 全局登出 

#### 退出统⼀认证中⼼，同时清理官⽹及接⼊产品登录状态。 

## 10. 安全规范 


### 10.1 redirect_uri 

所有 redirect_uri 必须统⼀⽩名单管理。 

### 10.2 state 

所有授权请求必须校验 state，防⽌ CSRF。 

### 10.3 Token 安全 

access_token / refresh_token 禁⽌暴露于前端或 URL。 

### 10.4 client_secret 

#### 仅允许服务端保存。 

### 10.5 HTTPS 

#### ⽣产环境必须全链路 HTTPS。 

### 10.6 ⽇志安全 

#### ⽇志必须脱敏处理，不记录敏感信息。 

## 11. 标准输出能⼒ 

统⼀登录认证授权中⼼需向各产品提供：client_id、client_secret、redirect_uri 配置、logout_uri 配 置、 访问的票据、UserInfo、SSO、SLO、登录审计能⼒。 

## 12. 产品接⼊要求 

接⼊产品需满⾜：⽀持统⼀认证中⼼登录、⽀持官⽹免⼆次登录、⽀持 Unified UID 映射、⽀持⾸次 绑定、⽀持本地登出、⽀持全局登出、满⾜统⼀安全规范。 

## 13. ⾮建设范围 

#### 本项⽬不包含：统⼀产品业务权限、统⼀租户体系、统⼀⻆⾊体系、统⼀菜单体系、统⼀账号库合 

#### 并。 


## 14. 验收标准 

### 15.1 功能验收 

官⽹统⼀注册登录完成；官⽹进⼊产品免⼆次登录；Unified UID ⽣效；⾸次绑定流程可⽤；SSO ⽣ 效；SLO ⽣效。 

### 15.2 安全验收 

redirect_uri ⽩名单；state 校验；token安全；client_secret 安全；HTTPS；⽇志脱敏。
