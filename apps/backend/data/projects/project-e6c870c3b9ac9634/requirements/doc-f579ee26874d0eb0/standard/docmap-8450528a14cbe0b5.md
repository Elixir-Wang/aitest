# 对话历史-支持筛选用户名&按对话ID导出

## 1 需求背景

Agent在实际生产使用与问题排查过程中，无法基于用户名进行有效筛选，导致在定位特定用户对话或区分不同来源调用时成本较高，影响问题复现与分析效率。

同时，导出历史对话数据，用于与客户共同分析badcase，尤其是在催收等强流程、多轮交互的业务场景中，需要还原完整的用户行为路径。然而当前导出方式以单轮对话记录为主，导出文件无法以"会话"为维度罗列，导致在进行问题定位时，需要额外进行数据操作，分析成本较高。

新增顶部筛选项【用户名】（username），点击后，展示使用该Agent的所有用户名，支持用户筛选。筛选后下方对话历史页面展示该用户的对话历史。

- 筛选交互与原有逻辑保持一致
- 若用户名过长时，用户名只展示部分+...。悬停后，在上方展示全部用户名。
- 用户名按照名字升序排序

### 2.2 按对话ID导出

需在现有单条日志导出的基础上，以【对话ID】分组后，取分组里会话时间降序排序后的最大值，比较分组间的这个最大值，按照最大值对应的对话id 降序排序，将同一会话内的所有对话内容按提问时间顺序进行罗列（升序）。

同一对话ID下的所有日志必须保持整体连续，不可拆分或跨会话分散导出。
